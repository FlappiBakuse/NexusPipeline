# 当前待验证事项

当前目标版本为 Host 0.18.0、SDK 0.1.0、官方插件 0.5.0。当前行为由各领域文档说明，
源码、验证和性能结果由对应仓外回执绑定。本页只维护仍未完成的事项。

| 项目 | 完成条件 |
|---|---|
| 366 天压力目标 | 同数据下继续压低启动/队列逻辑读写及稳定闲时，分别核对原始 99%/95% 目标；保留收益与回退指标 |
| 更新维护与队列 CPU | 对实际耗时增加采集 CPU 热点；当前剩余截图时序前缀及冻结计划读取需等价保护证据后再调整 |
| 首次启动加载 | 继续区分 Host/桌面映像、系统 CreateProcess 和插件原生闭包，保留必要信任与持有期核验 |
| 桌面稳定闲时 | 进程逻辑计数由桌面 IPC/绘制主导；后续优化以实际文件、管道及调用栈归因为依据 |
| 组合历史查询 | 将混合历史的组合筛选下推服务端条件与稳定游标，以 limit + 1 验证空组合和前瞻读取有界 |
| 执行中断定位 | 保留未复现的故障证据，按真实 writer、日志与停止记录继续定位，修复须有定向复现 |
| 模拟器与真实账号业务 | 真实设备、游戏、脚本、签到及外部通知继续独立验收 |
| 原生环境与性能矩阵 | 多屏 DPI、Explorer/快捷方式、长期性能和未运行的 SDK runtimeConsumers/lifecycle 按实际范围补验 |
| 正式发行 | Production 信任、正式候选、PR 检查与 0.17→0.18 独立目录/实例发布闭环仍需对应授权 |

普通启动处理当前恢复候选，完整历史由访问、维护和显式诊断验证。实例独占、writer 停止证明、
未知字节保留、恢复授权、秘密隔离及未知副作用检查继续有效。正式发布规则见[发行](developer/release.md)。
