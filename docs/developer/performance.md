## 资源口径

CPU 使用完整实例进程族的累计 CPU 差分，按全机逻辑处理器数量归一，保留已退出短命后代。
同时报告平均、采样峰值、采样间隔及有效峰值窗口；P95 与峰值分列。
内存使用进程族私有工作集平均及峰值，私有提交、GPU 内存和采集器开销另列。
身份由 PID、内核创建时间、可执行摘要和实例/运行标识共同确认。

进程逻辑 I/O、逐文件 FileIO 请求和实际设备读写分别统计。
逻辑 I/O 包含管道、IPC 等活动；FileIO 请求可能包含缓存与非缓存层的重复事件。
设备计数按进程及路径归属，整机其他进程和未知归属保持单列，不分摊为软件读写。
未知路径、丢失事件、缺样本、异常间隔、产物变化和显示条件变化必须写入报告。

诊断观察器与普通复测分开运行。首次进程内读取和同进程复用分别报告；保留操作系统缓存状态，
不清空全机缓存制造冷盘。并发阶段、嵌套计时及不同采样窗口分别解释。

## 产品目标

预算政策 v3 适用于 0.18.0 本地成品验收，保留原始目标与历史判定。
参考设备为 Ultra 5 230F、32 GB、1080p、100% 缩放；新测量声明实际设备、数据和显示条件。

| 场景 | 目标 |
|---|---|
| 默认主题、全部可见动画、无执行任务 | CPU median ≤3%，P95 ≤8%；另列平均和采样峰值 |
| 同一可见闲时 | 私有工作集 P95 ≤250 MiB，期望 ≤200 MiB |
| 隐藏且保留草稿 | CPU 不高于同轮可见闲时；展示帧、展示轮询、媒体请求归零 |
| 100 次导航后稳定闲时 | 仍满足闲时门槛；私有工作集 P95 相对初始增长 ≤20 MiB |
| 常规启动 | 进程创建至 Host ready 且关键首屏可操作的 P95 ≤4,000 ms |
| 366 天压力实例启动 | 可见首屏在 15 秒内，同时列出原四秒目标对照 |
| 日常页面导航 | 当前页关键结果提交并绘制的 P95 ≤250 ms |
| 366 天启动及队列逻辑读写 | 对固定原始基线分别争取下降 99%，持续报告绝对字节 |
| 同数据稳定闲时逻辑读写 | 对固定原始基线分别争取下降 95% |

不得用最新一轮替换原目标分母，也不在观察结果后改阈值。空窗口、HTTP ready 与首屏可操作各自记录。
不通过强制 GC、工作集 trim、销毁 renderer、删除动效或截断用户历史达标。
前台预算保留按显示刷新率运行的粒子效果，既有轮次保留各自实际适用的预算与判定。
P0 原型的目标制定依据保留在[桌面 ADR](../decisions/desktop-shell.md)，不计作成品通过。

## 容量与超限

| 资源 | 上限或目标 | 超限处理 |
|---|---|---|
| 每订阅待处理事件 | 256 envelopes 且 1 MiB | 标记 gap，按权威状态/游标恢复 |
| 每运行实时日志尾 | 500 条且 1 MiB | 标记早段未驻留，持久原文仍可读取 |
| 全 tab 日志尾 | 4 MiB | 回收无引用窗口，保留游标 |
| 历史日志单次读取 | 目标 512 KiB | 分块读取，DOM 只保留可见行及 overscan |
| 图片在途请求 | 每 tab 4 个 | 可见优先、去重，scope 释放即取消 |
| 编码图片及下载缓冲 | 各 32 MiB | 按预算准入；无长度响应预留下载上限 |
| 同时解码 | 2 项，目标 64 MiB 像素 | 排队，取消的等待者不创建解码器 |
| 页面首批列表 | 默认 50 项 | 服务端游标分页 |
| 历史页缓存 | 8 页，每页 ≤131,072 字符 | 淘汰旧页，保留最多 32 份游标书签 |
| 实时 PNG | 每帧 8 MiB | 超限或截断拒绝，不落临时 PNG |

这些预算不包含浏览器临时拼接副本、画布和 GPU。超大原图可独占解码，峰值在对应场景单列。
资源 key 绑定实例、身份和修订；权限、实例或 owner 变化清理缓存。
后端不推送无界快照，慢订阅不阻塞执行；秘密由专用内存 owner 持有。

## 验收方法

常规可见窗口预热 30 秒、采样 90 秒；隐藏稳定 15 秒、采样 60 秒。
生命周期覆盖 20 次隐藏恢复和 100 次导航，稳定 30 秒后采样 90 秒。
完整产品矩阵包含空实例、日常、十万历史/五千截图、大详情/长日志、重连与反压、
扩展失败释放、服务/renderer 失败、退出与浏览器模式。各场景分别报告，不挑最低值。

366 天回归使用同一份 3,660 条原始记录，每条 1,000 行日志、5 个截图引用，保留原始内容指纹。
十个假通用脚本绑定一个用户和一个队列，两个回环通知实例绑定全部脚本。
普通复测包含启动、三轮十脚本队列、180 秒稳定闲时和 600 秒长窗；每轮应完整产生十份日志、
二十次 HTTP 200 且无重复投递。真实专项绑定保持禁用。脚本、数据生成、输入与结果各自记录来源。

180 天混合重试场景独立建立输入身份：十个假专项实例各发现十项任务，绑定同一用户和队列。
每天随机分配五个首次成功、三个任务二失败后局部重试成功、两个在任务三和九中途崩溃后最终成功。
每个实例每日一组历史；每次调用，包括各次重试，各保留约五百行日志及两张合成截图，并保存完整任务结果。
两个通知实例启用并绑定全部用户脚本绑定，接收端仅使用本机回环地址。
分别采集可见闲时、隐藏闲时和实际队列运行的 CPU、私有工作集、逻辑 I/O 与设备 I/O，
历史按日分布、重试链、内容指纹及通知次数随输入与产物一并核验。
容量扩展在正式性能窗口后单独执行，保留原输入及内容；全量准入、实际队列、冷启动和中断通知恢复分别记录。

| 修改范围 | 必须保持的产品假设 |
|---|---|
| 启动与按需读取 | 普通启动不重放完成历史；当前恢复、格式拒绝和独立历史诊断仍有效 |
| 证据复用 | 篡改、替换、追加、外部提交、新拥有期和淘汰触发核验，超限走普通读取 |
| ZIP、旧树和 blob 清理 | 安装、回滚、执行、通知及未知引用保留；分页、中断续做与原回执重放有效 |
| 日志与预览 | 增长只消费新增前缀，冷读结果一致；连续预览零 PNG/blob 写入，归档仍可用 |
| 无变化后台 | 无到期工作不做业务持久写入；真实事件、重连、取消、到期与恢复仍生效 |
| 历史页面 | 容量内 1→2→1 复用；权限、筛选、实例及明确刷新失效，旧详情按用户访问读取 |

源码、依赖、运行时、数据和软件绑定摘要；纯文档收尾按[工作流](workflow.md)记录 docs-only delta。
每次复测同时保留收益、回退、未运行项和归因缺口。新增修改只由实际调用、读取内容及定向反例支持。
