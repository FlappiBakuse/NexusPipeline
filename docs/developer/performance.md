# 性能与有界资源

预算政策：v2，适用于 0.18.0 的本地成品验收；保留 v1 的原始目标与历史判定。
本文件规定目标，不宣称完整软件已经通过。P0 选型见 [桌面 ADR](../decisions/desktop-shell.md)。

## 资源口径

CPU 为完整实例进程族的全机归一累计 CPU 差分，包含已退出的短命后代。
驻留内存使用完整族私有工作集；私有提交量、GPU 内存和采集器开销分别报告。
身份以 PID、内核创建时间、可执行文件摘要、本次实例/运行标识确认。
未知归属、缺样本、异常间隔、产物变化和不满足显示条件均不能作为通过轮次。

| 场景 | 原基准设备的回归目标 |
|---|---|
| 默认主题、全部既有可见动画、无执行任务 | CPU median ≤1%，P95 ≤2% |
| 同一可见空闲 | 私有工作集 P95 ≤250 MiB，期望 ≤200 MiB |
| 隐藏且保留草稿 | CPU 不高于同轮可见空闲；展示帧、展示轮询、媒体请求归零 |
| 100 次导航/详情开关后稳定空闲 | 仍满足空闲门槛；相对同轮初始私有工作集 P95 增长 ≤20 MiB |
| 启动 | 进程创建至 Host 就绪且关键首屏可操作的 P95 目标 ≤4,000 ms |
| 日常页面导航 | 操作至当前页关键结果已提交且绘制的 P95 目标 ≤250 ms |

启动目标采用实际关键结果，不以空窗口或仅收到 HTTP 200 作为就绪。
表中目标对应 Ultra 5 230F、32 GB、1080p、100% 缩放的参考设备。
新测量先声明设备、显示、数据、场景、视觉版本与目标依据；同时报告原目标对照、
修复前后趋势及用户可见延迟，不在看到结果后把阈值改到刚好通过。
超出适用目标时保留 FAIL 或未裁决，动态资源策略不构成自动通过。
P0 参考壳从内核创建至 shell.ready 约 2.33–2.36 秒，首次验证 Host 连接约 2.72–2.74 秒；
参考页面导航的每会话 9 个观测均不超过 140 ms。这些只作为目标制定的输入。
成品启动与真实业务页面时长仍须实测，不能直接复用原型结果。

仅 P0 固定参考 UI 的内存增长上限获批为 60 MiB；该例外不进入成品判定。
原始 20 MiB 检查和例外检查分别保存，不修改原失败数据。
不通过强制 GC、工作集 trim、销毁 renderer、删动效或截断历史来达标。

现役背景使用 Canvas2D，按视口宽度绘制 36、56 或 80 个粒子与距离 104 像素内的连线，
保留旧版尺寸分布、主题透明度、随机速度与漂移、原生抗锯齿和最高 2 倍像素密度。
绘制后端是否使用软件或 GPU 由实际上下文和诊断确认，不由 Canvas2D 名称推断。
可见窗口按 `requestAnimationFrame` 更新运动和画面；60 Hz 屏幕下约为每秒 60 帧，不人为降帧。
其他动画遵循自身生命周期。隐藏停止非必要展示，普通和秘密草稿仍保持各自 owner。
Host 使用后台工作站 GC，匹配本地交互、小规模请求与空闲驻留需求；执行工作继续由各自已拥有的进程承担。
启动、维护和已安装插件元数据的同步核验中，每个作用域最多保留 64 个目录句柄；
句柄请求属性读取和目录遍历权限，并拒绝共享删除，阻止这些路径被重命名或删除；
每次路径检查仍通过句柄读取当前属性和 reparse 标记，文件及未保留目录仍按路径核验，不缓存物理属性或业务结论。
安装证据 owner 在相同 64 项上限内补充保护自己的 journal 及声明的 payload 目录；已安装扩展准备从同一份文件树租约读取并验证 manifest。
运行时借用同一份已验证文件树保护，重查目录库存、reparse、身份及长度；只读文件与目录句柄直到最后一位借用者释放才关闭。
新安装的激活证据在发布队列的每次同步核验内复用有界目录与 blob 保护；离开核验即释放，不跨异步回调缓存安装阶段结论。
每个实例的发布队列拥有一条按需启动的后台线程，空闲等待事件；保持最多 64 项、逐调用上下文隔离及顺序执行，关闭后排空并释放线程与实例资源。
provider 注册读取已准备且持续只读保护的文件树声明，不再重复解压同一原 ZIP；仍核对原 ZIP 的身份和摘要、当前目录库存、单链接、文件身份及 manifest，并单独验证 worker/launcher 的实际运行时闭包。
宿主在调用扩展前完成 provider 输入和运行时闭包验证，再启动原五秒期限的扩展激活；注册仍重查当前文件保护和权限。进程创建至首屏的启动计时包含全部准备。
准备失败在确认任务故障及完成清理后恢复原树；超时、晚到故障和未完成清理仍保持隔离。
一次已安装扩展调用共用其安装证据 owner 持有的目录保护；每次同步校验临时进入作用域，
异步回调期间不携带线程本地作用域，调用结束后释放保护。重复校验继续读取当前属性及原有业务事实。
启动同步核验另按最近使用顺序保留最多 128 份已验证 blob 的只读保护，不持有内容数组；
保护句柄拒绝写入和删除，每次打开仍核对当前文件身份、长度及引用，离开作用域或淘汰后重新计算摘要。
启动来源、预算和重试清单复用同次 attempt 核验持有的总执行计划，不重复打开并解析相同输入。
取消状态的完整启动清单核验一次全局关联，单个 attempt 核验自己的操作，并通过索引拒绝任何丢失父引用的取消记录；每次仍读取当前 SQL 与物理 journal。
父 journal 和操作种类使用两个精确定义的非唯一派生索引；未知或改写索引仍拒绝，逻辑格式摘要不变。
检查先验证隔离副本的格式、身份和完整性，再为副本建立索引；原数据库仅在完成准入并持有实例租约后补齐索引。
Windows blob 读取逐次核对父目录，以不跟随 reparse 的句柄打开叶文件，再检查句柄属性、身份、长度和摘要；
保护期内复用摘要结论时仍核对新打开的文件句柄，不另行查询同一叶路径的属性。
桌面进程先以挂起状态注册原生身份，后端完成插件启动并监听后才执行桌面代码；
初始化失败时取消启动并回收已拥有的进程，桌面原有握手期限从后端已可连接时开始消耗。
截图原件弹窗在一份详情中复用节点，每次打开复位缩放和位置；隐藏后取消媒体读取并清空画布，详情结束后销毁。
控制请求正文按声明长度或小块起步，在原字节上限内增长；每次归还缓冲前清零，小请求不预留上限大小的数组。
Electron 主进程与 renderer 的 V8 年轻代 semi-space 上限为 1 MiB，约束交互产生的短命分配；
不限制保留的应用堆，不发送强制回收通知。容量与吞吐的关系见 [V8 年轻代参数](https://nodejs.org/api/cli.html#--max-semi-space-sizesize-in-mib)。
历史列表、详情及日期范围复用当前界面语言的 ICU 格式化器，切换语言时更新；
时长保留各入口的小数精度，日期范围按日历日期显示，避免每次打开详情重复分配原生格式数据。
Journal 读取复用临时缓冲，命中不可变文本时仍逐字节比较新读到的内容；
缓存未命中才复制持有字节，借用的缓冲不会成为文档的可变后门。
已发布扩展调用在资源租约内保护安装 journal、计划及元数据的原字节，嵌套端口复用同次调用的解析结果；
每次消费仍检查新增 journal 文件、当前 SQL 安装事实、启用选择、调用者权限与激活撤销。调用结束释放保护句柄。
历史截图在支持 WebCodecs 的浏览器中为每次可见绘制持有独立解码器，绘制后关闭帧和解码器；隐藏时取消在途解码并清空画布。
不支持对应格式时使用 ImageBitmap，仍在绘制或取消后关闭位图。
启动激活在回调拥有期保护并复用安装元数据，仍逐次核对信任、旧 writer 停止、当前 SQL 与 journal 名单。
安装证据先在保护租约内读取和绑定，资源预留后的激活结果使用该来源已验证的安装修订。
已安装且启用的插件启动最多并发四个，每个保留独立资源租约和激活拥有权；停止等待启动任务及全部 scope 的清理。
没有执行工作上下文的嵌套端口调用逐层验证存活、借用和调用者，再统一核对同一份安装证据；执行工作分支保留逐层工作校验。
已拥有的目录句柄覆盖每次同步消费和启动来源核验的完整调用链，仍从句柄读取当前属性；作用域不跨越 await。
执行服务的同步启动初始化也使用同一有界目录与 blob 保护，覆盖日志、图片、执行预算、重试及调度的启动核验；未知输入仍按原规则拒绝。
PC 执行历史的目标证据与阶段证据在单次核验内共用只读 SQL 连接，由目录及实际文件句柄固定数据库身份。
每次查询结束即释放命令和 reader，下一次查询重新观察当前 SQL 事实；核验结束关闭连接和保护句柄。
数据库启动准入和 journal 恢复分别为其单个数据库文件持有同步只读连接作用域，复用原生连接的 schema 加载。
每个读取保留独立事务及当前事实校验；作用域退出先清空对应连接池，再释放文件与目录保护，检查副本按原流程回收。
只读配置清单、Job 关闭清单和恢复准备为单个父 journal 复用已保护的解析结果；切换父 journal 即释放旧保护。
保护上限沿用 256 个修订和 16 MiB，超限回到完整读取；每次读取仍核对目录清单，SQL 绑定及恢复判定逐次执行。
执行历史逐修订检查结构和转移，全部不同的目标证据在其首次完整上下文中逐项核验；不可变目标与 PC 阶段文本按当前原文复用解码。
单次完成状态计算共用当前日志已解析的 writer 和结果集合，保留每个步骤的角色、钩子及采集完成检查。
完整执行核验在其私有计划拥有期内，为当前一个原始修订复用 writer、结果和完成状态三类不可变解析集合，每类最多 1024 项。
切换原始修订即清空集合，其他视图、其他计划及超限集合执行完整解析；作用域结束后释放全部派生结果。
HTTP 操作权限分类读取激活时冻结的权限声明；正文接收后，实际调用才取得安装证据租约，
并在回调前后检查当前事实和调用者权限，避免权限分类重复读取同一安装历史。

## 容量与超限

| 资源 | 起始上限 | 超限处理 |
|---|---|---|
| 每订阅待处理事件 | 256 envelopes 且 1 MiB | 标记 gap，停止增量应用，按权威状态/游标恢复 |
| 每运行实时日志尾 | 500 条且 1 MiB | 显示早期段未驻留，持久原文仍可读取 |
| 全 tab 日志尾 | 4 MiB | 回收无引用窗口，保留读取游标 |
| 历史日志单次读取 | 目标 512 KiB | 分块/游标读取，DOM 只保留可见行及 overscan |
| 图片在途请求 | 每 tab 4 个 | 可见优先、去重；scope 释放即取消 |
| 压缩图片驻留 | 目标 32 MiB | 回收无引用 Blob/URL；保留原图读取入口 |
| 解码像素估算 | 目标 64 MiB | 使用有界预览，释放无引用项 |
| 页面首批列表 | 默认 50 项 | 索引游标分页，不全量加载历史/图片 |

字节、数量、时间和所有权各自明确；哪个容量先达到就采用对应限流/恢复策略。
秘密不放入普通编辑模型、普通 DTO、日志或持久草稿。
资源 key 包含实例、资源身份和修订，不跨用户/权限/实例复用受保护缓存。
后端不推送超过已协商容量的无界快照，慢订阅不能阻塞执行。

## 验证范围

成品覆盖空实例、日常、10 万历史/5,000 截图、大详情/长日志及受控事件压力数据集。
验收包含空闲、隐藏恢复、导航、筛选分页、详情图片、重连/反压、扩展失败释放、
服务/renderer 失败以及退出/浏览器模式，分别记录功能、采集和预算结果。
数据集、工具、源码、运行时和软件均锁定摘要；真实游戏不是本地完成条件。
P0 SQLite 查询实验和四插件纵切不充当这些成品场景通过。

常规可见窗口为预热 30 秒、采样 90 秒；隐藏稳定 15 秒、采样 60 秒。
生命周期另做 20 次隐藏恢复和 100 次导航，随后稳定 30 秒再采样 90 秒。
短窗口 P95 为描述性统计；按场景逐轮报告，不合并场景或挑最低值。
键鼠活动单独记录，实际前台/视口变化或明显争用按原始时间线判定。
源码或输入变动后明确新身份；加测须有原因，不自动替换失败或自动放宽门槛。

## 有界读取与展示

数据库检查复制与首遍 SHA256 在同一次流式读取中完成；准入后仍独立核对原始文件组新鲜度，
副本完整性、未知格式拒绝及失败证据不变。重试启动清单按 64 项主键页遍历，预算观察在同一检查中
最多复用一份仍受只读句柄保护的计划，切换计划或结束检查即释放。
重试与日程 owner 各自保留最多 64 项候选，以实例数据库提交序号失效；重新启动会重建。
候选只减少查询，实际受理仍重新准备和核对当前权限、预算、资源及持久事实。
事件将持久计数和定义修订与执行进度分开失效，完整诊断只由诊断入口读取。
图片下载缓冲与 Blob 租约分别限制为 32 MiB，最多四路下载；无长度响应保守预留下载上限。
这个限制不包括浏览器的临时拼接副本、解码帧、画布和 GPU，整机报告仍须分别度量。
缩略图宽度按 64 像素档调整，减少微小布局变化导致的重复读取。
LiveScreenshot 只缩放预览至最高 360 像素高，普通原图路径不变；前端用显示元素完成单次解码。
解码队列最多同时两项，按目标像素估算 64 MiB 准入；取消的等待者不创建解码器。
单张原图超过该目标时独占解码，保留原分辨率入口，超限峰值须在对应场景报告中单列。
队列指标不代表画布或 GPU 已释放，关闭后整机资源回落仍以实测为准。
