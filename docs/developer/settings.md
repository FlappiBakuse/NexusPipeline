# 宿主设置

Core 的 `HostSettingsPolicy` 拥有可选值、端口冲突、保留天数与设置修订规则。
普通设置不含访问令牌、代理密码或秘密草稿。
SQLite 保存关系化的不可变修订及当前指针；首次建库才使用 Core 默认值，缺少当前指针时不重建默认值。
扩展偏好随修订保存，包括已卸载扩展的禁用选择。

每次保存绑定 operationId、主体、原请求摘要和 expectedRevision。
设置修订、当前指针及原操作结果在同一事务中提交；SQL 失败不会发布任何字段。
重试返回原修订，后续的新修订不会被旧操作重放覆盖。
完整诊断在隔离副本上验证当前设置，未知值保全原始八库与回滚日志组。

## 即时设置与界面偏好

设置页的有效输入完成后立即提交。命令串行合并未发送的字段变化；失败恢复确认值，未知结果保留原操作并只读核对。秘密输入仅在当前设置视图内存中存在，提交或离页后清除；在途秘密命令独立结算。

| 入口 | 生效及关闭规则 | 显式取消 |
|---|---|---|
| 宿主设置 | 填写或选择完成后提交，重启项显示待重启原因 | 使用各业务动作的取消语义 |
| 今日概览布局 | 调整后即时提交；保存、关闭、Escape 保持当前值 | 提交还原本次打开前的布局 |
| 游戏活动设置 | 调整后即时提交；保存和关闭保持当前值 | 提交还原本次打开前的活动设置 |
| 自定义壁纸 | 上传、选择、排序和效果变化即时提交 | 各业务动作自行取消，页面没有草稿取消 |

这些入口不注册编辑草稿，不提供草稿恢复或重试保存按钮。布局与活动的撤销基线只属于当前弹窗，页脚动作共用最小 80px 宽度。

语言、展开、置顶与布局由界面设置命令 owner 按字段合并，修订冲突保全其他位置的更新。活动与壁纸写入归插件激活期 owner；页面卸载释放展示资源，已受理命令继续结算。编辑草稿规则见[Web 状态](frontend-state.md#编辑草稿)。

## 设置与系统效果

`HostSettingsService` 使用实际实例租约，普通设置保存持有 `settings:host` 变更租约。
仅修改扩展启用偏好时，持有宿主设置引用租约、偏好写租约及各变更扩展的变更租约；
不影响该扩展的运行可以继续，引用该扩展的执行仍阻止修改。两类保存均核对当前修订并在提交后发布运行视图。
运行视图显式接收实际启动的监听、桌面和插件源参数；保存不同选择时返回重启原因。
可即时读取的选择由新的运行快照公开，启动时确定的服务参数保持原实际值。
Web 端口接受 0 或 1024–65535；0 表示下次启动由系统分配，MCP 仍使用独立固定端口。
启动时独占保留 Web socket，再把同一 socket 交给 Kestrel；桌面授权绑定该实际端口，
不通过关闭探测 socket 后重新绑定来猜测可用端口。保存值 0 与 status 的实际端口分别展示。
已知旧的固定端口状态表在持有实例租约、验证旧指纹和只读准入后原子升级；
保留全部设置修订及引用，提交前核对新目录和外键。未知表形状继续保全拒绝。
自启动变更必须经过系统配置用例，直接普通保存会拒绝缺少系统副作用的请求。

自启动定义绑定实例、登记 ID、用户、动作及时间；XML 声明当前用户登录触发、最高权限与单实例运行。
类型化 `IStartupRegistrationEffects` 端口分离只读检查、新建和精确拥有权删除。
原生适配器使用 Task Scheduler 的 `TASK_VALIDATE_ONLY` 检查 XML，读取前后保持原登记不变。
启用前核实当前进程已提升权限；未提升时在设置事务前拒绝，并提示以管理员身份启动软件，不留下待恢复意图。
缺少任务仅接受精确缺失 HRESULT；其他查询失败不会被当作未登记。
参数与受控进程共享同一 Windows 编码器，并由系统解析器验证空值、引号、尾部反斜线与 Unicode。
新建固定使用 `TASK_CREATE`，已存在且定义不同的任务不会被替换；调用期间持有匹配摘要的可执行文件及目录。
删除前再次核对完整定义。Task Scheduler 不提供原子的 compare-and-delete；实例租约串行化合作的拥有者，同 Windows 用户仍是信任边界。
创建任务仅授予当前用户和 SYSTEM 的登记权限，不调用任务启动。
原生约束来自 [Task Scheduler API](https://learn.microsoft.com/en-us/windows/win32/api/taskschd/nf-taskschd-itaskfolder-registertask)。

设置修订与 `nexus.startup.intent`/1 在同一 SQL 事务提交；冻结实例、操作、原登记摘要、目标动作、可执行身份和创建者完整进程身份。
`HostSettingsService` 先发布已保存快照，再进入持久效果门禁。系统调用失败保留已保存值，返回独立的 Quarantined 效果状态。
运行视图的 AutoStart 在效果确认前保持最后已确认值；`StartupEffect` 显示未闭合意图，不把保存值当成已登记结果。
相同 operationId 返回已接受结果及当前效果状态，不重新执行系统调用。

完整诊断在副本核对意图格式、原/目标设置、登记历史与当前指针，并确认创建者已停止后才打开原库。
恢复仅接收只读 inspector：进入门禁且完整登记符合目标时补齐 SQL，否则隔离；未进入门禁不主动登记。
系统意图拥有独立的持久资源保留，普通 journal 发布不会清除它。它阻断设置/自启动资源与整机关闭，其他资源仍可准入。
待核实记录由 SQL 再次约束，不能仅靠运行视图解除后绕过。

`storage-settings` 运行普通事务、保存失败和十个启用/停用强杀边界；未知元数据在原库打开前保全拒绝。
`windows` 验证受控登记端口及原生只读 XML/参数契约。自动化测试不创建、删除或启动用户真实任务，不触发 UAC。
HTTP/CLI/MCP 与桌面维护入口使用共享用例；整机自启动体验留给最终人工验收。

界面偏好的事件元数据仅读取当前实例已发布的修订号，不排入执行任务的串行发布队列。
启动先读取持久偏好，成功保存或显式读取后更新修订；实际内容读取、CAS 保存及未知格式拒绝仍由原 owner 执行。

扩展偏好 HTTP 保存和运行时协调通过现有资源 owner 等待占用变化，最多五秒；没有重复提交或循环重发业务命令。真实执行引用未释放时仍拒绝，原激活期限不变。偏好提交前重新核对当前请求权限、取消、实例租约和设置修订。

启动命令模板复用已验证安装清单的 launcher 摘要；直接 Host 入口借用当前实例持有的映像证明。
模板准备核对路径和可读性。实际启用自启动仍在系统效果入口持有文件/目录并核对实际字节，错误摘要和篡改拒绝创建任务。
