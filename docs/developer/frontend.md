# 前端行为、公共组件与页面边界

`apps/web` 是浏览器与 Electron 共用的 Vue 应用。Host 提供 Web 资产，桌面通过受限原生桥加载同一界面；公共 Custom Elements、SDK 和 typed control client 共用现有契约。

## 页面与能力归属

| owner | 职责 |
|---|---|
| App shell | 实例、权限、连接、导航和界面会话 |
| Automation | 脚本、账号、绑定、队列的编辑状态及具名命令 |
| Records | 查询、分页、账号范围和稳定深链 |
| Logs / Media | 共享请求、有界缓冲、可见性和取消 |
| Extensions | 插件模块、挂载 scope 和生命周期通知 |
| Settings | 即时设置、确认值及原写入结果核对 |

页面取得所属任务需要的窄接口。公共组件只依赖公共行为，页面私有类型留在页面层；派生 lookup 随权威修订更新。已有 EventFeed、LiveLogs 和 MediaPool 继续管理共享资源。

## 表单与公共动作

真实保存使用明确的提交路径，其他原生按钮显式设置 `type="button"`。选择、探测、查询和修复预览保留父表单；脚本根目录选择后自动发现，用户处理真实多候选或缺失。

公共按钮、字段和动作集合统一 busy、disabled、键盘、焦点、校验与提交语义。Vue 封装适配模型与事件；弹窗页脚动作使用一致的最小 80px 宽度。开关行复用 `nexus-switch-list`，排序复用公共指针及键盘 owner。

宿主与插件设置分类共用展开、置顶、排序、定位和可访问状态。选择分类后展开并定位，重复选择收起；直接操作卡片标题清除旧置顶。快速切换保留最后选择和阅读位置，插件通过公开挂载能力贡献内容。

## 历史与登录的完整身份

账号历史链接由共用入口携带账号上下文，服务端详情、日志和图片沿冻结步骤过滤。整体运行入口使用运行身份；查询、稳定游标与容量边界见[启动与容量](startup-and-capacity.md)。

登录窗口先显示加载阶段，再访问已声明来源；候选凭据经过后端验证后返回编辑器。导航失败时原窗口提供刷新、完成并验证和取消。认证 iframe 的加载许可与凭据读取来源分别校验，秘密输入、披露授权和登录会话各自管理拥有期。

## 定向验证

真实父表单的非保存操作、账号历史深链、设置分类、草稿恢复与即时设置分别验证产品结果。保留焦点、最后数据可达、权限、取消和未知操作归属断言。

公共 ABI 改动扩到实际插件消费者；页面排版使用对应浏览器场景。命令见[验证规范](validation.md)，公开元素见[前端 ABI](frontend-abi.md)，读取及资源细节见[Web 状态](frontend-state.md)。
