# 启动反馈与原生桌面

原生启动覆盖层与 Web 界面准备页共用 `apps/desktop/startup-content.css` 和同一图标。背景、64px 图标、标题、单行阶段、进度与已用时间保持一致；Web 构建输入绑定这两份共享资源。未知总量使用不定进度，已知总量显示真实完成比例，阶段更新不重置计时。

桌面先导航到本次文档，再由该文档与原生桥共享签名会话连接。导航代次、发送方、签名与实例绑定检查保持；前端可用和 Host 完成信号均到达后才移除覆盖层。

读取展示偏好后，所属桌面的映像保护、摘要和进程启动在独立任务中执行，与数据库身份、格式准入及当前恢复重叠。Host 在取得原生客户端绑定前等待桌面任务完成；失败展示与退出也先等待该任务，再释放通道、签名器和进程保护。桌面任务只准备所属客户端与独立 profile，不读取或变更应用数据库。

## 入口与可见性

根目录 `NexusPipeline.exe` 是 WinExe，也是命令行参数入口。手动双击遵循已保存的桌面模式，并打开界面；`OpenOnStartup` 约束开机启动，不阻止手动打开。已有 Launcher 路径仍可使用，新安装的手动快捷方式指向根入口。

桌面模式在数据库准入之前创建主窗口，以本地覆盖视图显示真实阶段、阶段进度和已用时间。HTTP 就绪、签名桌面会话验证及前端准备完成后移除覆盖视图，同一个窗口显示控制台。外部图片和后台历史索引不阻塞切换。

轻量模式启动期间只显示托盘，服务就绪后按可见意图打开系统浏览器，不创建管理页面 renderer。开机静默启动与维护恢复继续遵循保存设置和已验证的恢复意图。

启动期间关闭窗口仅隐藏至托盘，数据恢复继续；就绪后保持隐藏。点击托盘或再次双击入口可恢复窗口。重复启动通过所属实例的本地激活通道唤起已有桌面，不再次取得实例租约或执行恢复。

## 生命周期与权限

`DesktopStartup` 持有实例租约与激活服务；`StartupProgress` 管理阶段、所属桌面及展示通道；`ApplicationHost` 仍负责准入、恢复、服务和业务生命周期。

`StartupPresentation` 在实例租约内通过查询专用连接读取当前展示偏好，持续保护数据库及已有 WAL 的路径。已有 WAL 使用独占内存索引并关闭自动 checkpoint，无 WAL 使用只读 immutable 连接；读取不创建副本或辅助文件。先检查实例与格式身份，非空 rollback journal 保留并拒绝。设置业务 owner 在普通准入后读取当前设置，未知格式保留原字节。

Host 在开始耗时检查前创建所属 Electron 进程族。启动通道使用当前用户限定的随机命名管道与每次启动 nonce，服务端核验实际客户端 PID。消息有大小和类型限制，只传递阶段、就绪地址、失败、原生菜单选择和窗口唤起。启动覆盖视图单独使用受限 preload，不能调用业务 API。

控制台仍从已绑定 Host 的回环地址加载，业务动作仍使用原有签名会话、来源和主 frame 校验。启动失败显示可复制的脱敏原因和错误码，退出不会重试恢复；运行时无法创建时使用原生错误对话框。

## 托盘和图标

Electron 持有唯一托盘图标。右键经内部通道调用 Host 的 Windows `TrackPopupMenuEx`，菜单由系统绘制：轻量模式、页面重载、分隔线、退出。启动期间业务动作禁用；失败后允许退出。左键恢复桌面或打开浏览器。

菜单 owner 为可见的零面积工具窗口；打开前临时连接前台输入线程并核实 owner 已成为前台，随后解除连接。取得前台失败时取消此次菜单，保持通道可用。菜单关闭后投递空消息并销毁 owner，点击其他窗口与 Escape 均由系统菜单循环处理。

轻量切换、重载和退出继续使用现有设置 CAS、草稿准备与关闭许可。菜单不在打开前请求 HTTP，语言跟随当前桌面设置。

官方图标源位于 `apps/desktop/nexuspipeline.ico`，四个 .NET 程序与桌面窗口、托盘共用。桌面装配在已核验的官方 Electron 归档上写入产品图标，再计算最终产物清单；回执分别记录原始 EXE、图标、处理工具及最终 EXE 身份。

## 终端使用

显式 `serve`、`control`、`--version` 按需连接调用者控制台，保留继承的输入输出和文件/管道重定向；不会分配新控制台或隐藏用户终端。worker 继续使用父进程提供的标准流。

GUI 子系统的进程等待由调用者负责。需要等待和退出码时：

```bat
start "" /wait NexusPipeline.exe --version
echo %ERRORLEVEL%
```

```powershell
$process = Start-Process -FilePath .\NexusPipeline.exe -ArgumentList '--version' -NoNewWindow -Wait -PassThru
$process.ExitCode
```

自动化应持有进程句柄，等待结束后读取退出码。重定向 stdout/stderr 的调用继续保留原始字节。

## 定向验证

验证启动展示快照的只读与未知格式保全；原生桌面 fixture 覆盖同窗进度、隐藏后就绪、轻量模式、重载与草稿、模式切换和签名退出。真实产物另覆盖无控制台启动、CLI 标准流、重复激活、系统菜单、图标、数据库准入和维护重启。

单独记录启动请求、进度首绘、HTTP ready 与控制台首绘。首次反馈提前不作为数据库检查性能提升的证据。当前候选的命令、结果和未运行项以本轮外部验证回执为准。
## 插件与首屏加载

Host 启动时从同一数据库读事务选择启用且已安装的插件，激活时继续执行安装证据、授权与载荷校验；启动选择不读取用于插件中心展示的完整列表。最多四个插件同时激活。

网页准备先确认会话、权限与基础快照，再并发激活已启用插件，准备当前页和全局外观。前端模块最多六个并发，入口与样式通过单插件批读入口准备。当前页准备最多占用首屏五秒，超出后保持加载任务并显示已有界面；其他顶层页默认只读数据在展示后预热，不参与首屏屏障。静态页面资源随主包加载，后台准备不启动页面轮询和用户业务操作。

前端实例绑定浏览器文档、宿主实例和插件激活身份。普通导航、隐藏恢复和事件连接短暂中断保留已激活模块；重连核对身份，仅替换身份变化的插件。权限或宿主实例变化撤销旧任务。浏览器刷新、新标签页和桌面渲染进程重建会重新初始化前端。

活动插件读取总览与已有本地封面，并使用与页面可见性无关的 Blob 解码；挂载复用已验证图片。宿主图标使用相同的独立解码方式，并限制像素大小。准备不等待隐藏页面的绘制回调，不触发脚本、游戏、签到或通知。

全屏准备层仅用于首次展示。后续准备和重试保持已有页面、草稿和插件实例。读取或模块加载发生暂时网络错误时，以一秒、三秒、十秒间隔最多重试三次；权限和协议错误直接报告。认证或基础快照首次失败显示连接错误。取消和权限撤销阻止迟到结果发布，窗口隐藏不影响准备和隐藏意图。

桌面覆盖层通过校验主 frame 的内部 IPC 接收真实阶段与完成数量。浏览器刷新和轻量模式的默认浏览器使用网页准备层。性能条目分别记录 `nexus.plugins.prepared`、`nexus.pages.prepared`、`nexus.interface.presented`，与 Host HTTP ready、进度首绘分别分析。

插件中心后续刷新沿用公共进度动画。设置页面新会话默认展开服务行为，后续点击保留当前会话选择。

## 桌面后台等待

登录与维护通道使用最长 25 秒的可取消等待，真实请求到达立即唤醒。等待中的登录连接继续维持可用性，
请求仍绑定原会话、调用者及取消信号；关闭、撤销和晚到结果沿原生命周期处理。
Windows 桌面关闭 Chromium 延后的 DX12 信息采集子进程，普通 renderer/GPU 绘制和可见动画保持。
主进程与 renderer 的 V8 年轻代 semi-space 上限为 1 MiB，约束短命分配；不限制保留的应用堆，不强制回收。
验收分别核对原生登录唤醒、取消、维护关闭、正常 GPU 留存及动态进程族 FileIO。
