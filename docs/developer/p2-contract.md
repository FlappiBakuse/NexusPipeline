# P1 后端的 P2 消费约定

本表固定补充开发后的业务语义。wire 结构以 `contracts` 为权威，SDK 版本仍为 0.1.0。
P2 不应按旧审计快照中已修复的缺口实现替代逻辑，也不应在浏览器重建恢复或授权权威。

| 领域 | 消费约定 |
|---|---|
| 队列 | 保存脚本组和用户顺序，准入时展开当时启用的账号绑定；已受理计划固定。没有固定绑定队列产品模式。不可用项及其依赖有跳过结果，可独立项继续。 |
| 等待日程 | 无关编辑不使已等待 occurrence 永久失效；来源被删除、停用或改时后取消。重验证保留原身份、预算和 deadline。同队列同触发时刻只运行一次。 |
| 时区与故障 | 保存时拒绝未知时区；已有坏项隔离，合法项继续。调度循环故障状态可见，不能把所有未来工作显示成正常等待。 |
| 成功次数 | 每个确定成功的绑定独立记账，后续取消不撤销；业务日期取运行开始日，重复投影不重复计数。 |
| 非零自然退出 | 无日志监控及业务判定时沿用旧版有效成功语义；实际 exitCode 和 Engine.Failed 保留，原始 Business.NotApplicable 不伪造成 Succeeded。整体结果、重试及额度消费宿主的有效结果，UI 不以 exitCode 或原始 Business 单独重算。 |
| 普通重试 | 只有冻结声明、宿主策略、可靠停止和配置恢复同时满足且预算尚存才可重试。取消、总超时、崩溃及未知停止不获得普通重试资格。 |
| 远程 | 已认证远程可使用普通设置、插件协调及受运行授权的预览；原生操作、秘密明文及维护保持本地。保存的开关撤销也终止既有 SSE。 |
| 同源 | 合法 DNS 名称须与实际 listener、Host、Origin 一致，不信任 Forwarded 头授予身份。当前 listener 的真实网络正向验证为 IPv4；不宣称 IPv6 listener 已实现。 |
| 就绪 | 首轮运行天数、启动队列及分钟元数据先于 ready 提交；已触发的实际任务继续在后台执行，就绪不表示所有执行均空闲。 |
| 重启 | 独立重启不要求更新包。重启交接的 202 表示准备受理，连接断开后重新连接并检查实例就绪，不能将受理当作新宿主已就绪。 |
| 更新 | develop 同版本不同摘要允许刷新，可信 stable 可替代同版本 develop；相同摘要不重装、不降级，stable 同版本替换仍拒绝。单次网络超时不停止后续自动检查。 |
| 启动更新 | 启动前消费持久 NextStartup；自动发现后的交接前失败保留同 operation 的 NextStartup，下一次启动继续。不能在 UI 另建重试更新操作。 |
| 留存 | 使用保存天数，保护活动、待恢复及通知引用。逻辑隐藏不等于物理删除；仅宿主自动留存的完整 NotExecuted 批次可按当前设置获新授权续办。未知、隔离和手工清理不自动重放。 |
| 事件与凭据 | 共享快照按保存变化发布，客户端断线按水位重同步。凭据每次使用仍检查当前生产者及撤销；不因复用验证而信任过期凭据。 |

用户已明确选择旧版自然退出成功、仅脚本组队列及限定自动留存续办。
这些选择不开放秘密、不放松 writer/Job、文件归属或未知恢复证据校验。
完整页面、全部 14 插件业务和成品性能仍分别属于 P2、P3、P4。
