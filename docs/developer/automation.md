# 自动化定义与交换

Core 的 Automation 维护根、脚本、用户、绑定、队列和调度定义及引用规则。
用户的 `order` 是独立的全局顺序，范围为 0–4095；持久读取按该值及 canonical 用户 ID 排序。
脚本执行按此顺序选择用户，不把绑定的 `priority` 当成全局用户排序。
队列保存有序且不重复的 `scriptIds`；在准入时展开当时启用的有效绑定，并按全局用户顺序排列。
已接受执行计划冻结具体绑定，后续新增账号或顺序修改不改写它。队列列表的 `order` 范围为 0–4095，按该值及 canonical 队列 ID 持久排序。
定义导入导出必须包含用户及队列顺序，缺少字段时拒绝当前格式，不补造默认值。
SQLite 是持久事实来源；读取生成不可变目录，编辑以全局目录 revision 和实体 revision 比较提交。
用户删除只级联所属绑定，保留队列的脚本组意图；脚本删除移除对应组及其依赖边，保留其他组顺序和历史执行事实。
绑定 ID 固定其账号与脚本关系，调整关系需要创建新绑定。
脚本 ID 固定其类型与专项扩展身份；普通编辑保留该身份。

Platform 的 `AutomationDefinitionService` 与 `AutomationImportService` 使用同一实例租约、资源管理器和恢复索引。
Host 组合这些共同用例；完整 Web、CLI、MCP 传输和访问权限归后续控制面任务。
普通定义提交在关系事务内完成身份接受、实体修改和结果登记。
最后一个脚本附件引用移除前，在同一事务中登记清理 journal/outbox；结果携带持久 journal ID，文件完成情况单独查询。
清理隔离发布到共享恢复索引，阻断相关 blob 操作和宿主关闭。

`nexus.automation.bundle`/1 包含相对路径与显式附件索引。
导入先选择目标根并验证预览，预览摘要绑定真实目录身份及完整输入。
纯定义导入按已核对的目录修订绑定既有实体修订，保留其ID；应用仍核对原预览摘要和目录修订。
既有队列的非None完成动作保持不变时允许普通远程导入；新增或改变该动作仍要求本机权限。
通用模板按 operationId 派生稳定的新根、脚本和附件 ID；不同请求生成独立实例。
已接受请求先按主体、完整请求摘要与种类读取原结果，再进行新的路径预检。
原目录或原附件后来消失、目录 revision 后来增长，都不会改写已接受请求的结果。

纯定义导入使用一个 SQLite 事务。
带附件导入使用 [资产准备日志](../decisions/asset-preparation.md)：全部文件核验及收据闭合后，才原子公开定义和资产引用。
源文件在核验期间保持只读租约；内容寻址对象只独占创建，恢复不会重做缺少完成证据的复制。

准备导出在一个关系快照中读取定义和附件索引，再逐个核验并持有内容对象。
调用方取得独立 JSON 字节和受控附件复制接口，使用完释放整个导出。
多个导入来源的包内路径发生碰撞时，导出按资产 ID 生成独立相对地址。
通用模板只包含所选脚本及其附件；普通秘密字段、秘密密文和历史记录不进入定义交换。
内容缺失或损坏使整个导出失败，并释放已取得的内容句柄。

专项脚本的 `adapterResources` 显式覆盖原 `configurationPaths`，每项固定 resourceId、声明索引、快照内相对文件、定义修订、语法及读写/保护选择器。通用脚本与原执行 provider 使用空数组；当前交换格式缺少该数组时拒绝。声明的内容纳入原定义摘要与配置契约，不接收临时调用方路径或访问授权。

专项创建通过 `POST /control/v1/automation/scripts/discover`、CLI `script-discover` 与 MCP `script_discover` 共用只读来源用例，要求 `configuration.read`。请求明确目录和插件安装修订；只向声明来源发现权限的当前插件开放有界目录与 UTF-8 文件读取，拒绝链接、越界与目录身份变化。候选配置不创建账号或执行任务；本机单候选选定，多候选由用户明确选择。每个配置文件都有对应快照资源。新增或更改适配资源访问声明要求本机 `automation.declare`；远程和 MCP 可只读发现，界面明确提示在 Host 本机创建或选择配置。

Maa 实例创建先保存定义，再以明确的来源实例保存项目选择。选择操作 ID 在响应不确定时保留，确认或重放该操作不会重复创建定义；明确拒绝时保留草稿，并使用已提交的定义修订继续编辑。

绑定 `runDays` 使用 -1 表示不限、0 表示不参与、正数表示剩余天数；每日成功上限 `maximumSuccessfulRunsPerDay` 使用 -1 表示不限，0 非法。用户 `bindingOverrides` 分为 general、notification、advanced 三组，每组独立 `syncEnabled`；执行冻结有效值，关闭同步后原始绑定重新生效，覆盖不会改写原始绑定。
队列 `successDependencies` 的 `scriptId` / `requiredScriptIds` 表达更早脚本组的成功依赖。
依赖组的全部参与账号须确认成功，才可执行后继组；无参与账号或不可用组不能满足依赖。
未声明依赖的后组可继续。预览包含后端生成的组级说明，空组明确为无启用绑定；绑定级说明保持独立。
插件禁用或普通单项输入不可用产生跳过；全局恢复未知、容量不足、资源拥有权及结构性非法仍保留整体拒绝边界。
