# Web 状态与投影参考

## 状态与生命周期

`app/store.ts` 持有当前实例身份、权威自动化/设置快照、导航、普通内存草稿和一份共享订阅。
背景粒子通过 `requestAnimationFrame` 跟随显示刷新率，位移使用真实经过时间，保留圆点、连线和交互动画；
隐藏、减少动态效果与卸载停止帧调度。
导航准备失败保留当前页面与草稿；hash 深链在启动和浏览器导航时保留查询身份。
已访问页面保持实例，隐藏由明确的 visible 属性传入；页面不以重启 renderer 清理内存。
原生退出在写入未完成时拒绝，有普通草稿时确认；浏览器使用 beforeunload 保护。
签名维护许可与普通退出分开准备。设置页发起的重启请求等待原生窗口退出后才响应，
仅该请求可在维护准备时继续等待；其他未完成写入仍阻断交接，普通退出始终检查全部写入。

`control/client.ts` 在外部数据边界解码 typed 结果，限制响应大小和请求时限。
读取允许 owner abort；写入不随离页取消，连接失败返回带 operation ID 的未知结果。
页面先查询该操作或重读权威状态，不自动重发未知写入。
写入成功响应的 JSON 结构无法解码时同样保留原 operation ID 与未知结果，读取解码错误不产生写入身份。

通知编辑器把普通字段、原基线、原 catalog/task revision、目标和在途操作放在 store 的普通草稿内。
可见编辑器卸载后，原请求仍更新同一普通状态；秘密值仅由可见编辑器持有并在卸载时清除。
重开不提升旧草稿的修订，也不重新发送在途或未知写入。迟到成功不会关闭后来打开的其他编辑器。

字段配置、原生编辑器及专项修复同样将普通编辑状态和在途身份保存在 store 草稿中。

专项脚本实例不显示自定义完成标志与判断脚本入口，现有判定数据保持原值。实例级插件编辑面板仅挂载于已保存实例；新建草稿先通过根目录发现完成定义。弹窗内容中的 toast 和子弹窗关闭事件止于所属内容层，不触发外层弹窗关闭。
请求发出前登记原动作与目标，卸载后的结果继续归原状态；可见组件的退出不取消已经发出的写入。
字段配置保留首次选择时的绑定、资源修订及源摘要，重开不会悄悄提高旧草稿的 CAS 基线。
原生会话使用 session ID 恢复，完成操作身份不一致时继续保留待确认状态。

`control/event-feed.ts` 在每 tab 内共享 Host SSE，检查实例、流、序列、topic 和主体。
gap/超限/断线重取快照；隐藏与最后退订终止连接和重连计时器。
首次订阅的快照与导航已加载的同一流按修订对齐，不重复读取已就绪的自动化、设置、状态和界面快照；订阅前发生提交时补读变化项，流变化时完整刷新。断线或隐藏后重新连接仍刷新实时状态。
自动化和普通设置在连续事件中只在相应修订变化时重新读取，运行进度不触发整份设置重载。
订阅失败与普通命令错误分别保留，恢复后清除连接错误。

## 运行中心与实时日志

运行中心两张卡片可在父级网格中收缩，任务条在自己的横向滚动区展示；启动和长任务名称保持桌面及窄屏布局。
当前调用次数来自已登记 writer 对应的调用序号，计入同一 attempt 内的任务重试及恢复前已使用的调用；
显示上限使用该专项实例的冻结次数限制，持久 attempt 序号与内部 invocation 各自保留。
可见日志面板每 200 ms 合并增量文本与滚动更新，接收及持久归档保持全部原文。
面板隐藏、离开视口、切换步骤或卸载时释放订阅及待刷新工作，晚到回调继续绑定原订阅代次与步骤。
状态与日志传输的保活规则见[控制面](control-http.md)。

`control/live-logs.ts` 为最多四个身份窗口共享实时日志，每窗最多500行及256Ki UTF-16字符。
`RunningExecution` 仅向 `LiveLogPanel` 传入当前运行、尝试、步骤、角色、可见性和订阅能力；面板拥有窗口合并及跟随滚动。
日志顺序按 run/attempt/step/role 与 sequence 校验；完整原文仍通过持久日志的游标分块与下载获取。
原文下载直接连接用户选择的 WritableStream，不在 renderer 拼接完整 Blob；不支持流式保存的浏览器保留逐段下载。
Electron 文件系统写权限只针对绑定文档请求的已选文件，并显示精确路径让用户确认；其他权限、目录和读取请求拒绝。
权限处理沿 [Electron File System API](https://www.electronjs.org/docs/latest/api/session#sessetpermissionrequesthandlerhandler)，不增加任意路径写入桥接。

## 媒体生命周期

`control/media-pool.ts` 共享最多四个下载，去重同一资源，编码 Blob 缓存按32MiB排队准入。
最后引用消失或最后等待者取消即释放请求和 URL。编码字节、临时解码与可见画布有各自的寿命；
该缓存限制仅度量编码数据。媒体完整进程族的内存指标仍待实际设备验收。
`MediaImage` 直接解码池持有的 Blob，缩略图按显示尺寸与像素密度生成高质量预览，
原图详情保留源分辨率。临时 ImageBitmap 绘制后立即关闭，同时释放已完成绘制的编码租约；隐藏或卸载时清空画布；
解码失败和晚到响应同样归各自请求 owner 清理。
截图索引在内部按页读取，横向图库只挂载滚动视口与少量预加载项，列表提供总数和位置语义，
方向键及 Home/End 可访问尚未挂载的截图。滚动、隐藏和离开详情释放对应缩略图；
任意原图访问不受缩略图是否挂载影响。全屏预览提供缩放、拖动及自绘右键保存菜单。
历史详情按序展示最多99次实际尝试，各可见尝试独立读取日志和截图；日志默认折叠，完整原文按需读取。
运行信息使用冻结历史展示投影；缺失时间显示未知，不从累计耗时推算开始时间。
逐次调用的开始、结束和耗时来自已核验的进程身份与 Job 关闭证据，历史列表与详情按毫秒、秒、分钟、小时显示耗时。

普通表单、导入错误草稿与配置会话身份只保存在当前 tab 内存。
秘密字段由各编辑器单独持有，显式回读，keep/set/clear 不依赖空字符串推断，
不写入属性、localStorage、IndexedDB、共享普通草稿或日志。

## 设置与只读投影

界面语言、主题、概览布局与设置分类置顶/折叠归 `InterfacePreferences`，与宿主语言独立。
概览按运行状态、当前运行、历史统计三个单元排序和显隐；历史时长与次数两图共用一个布局单元。
读取保留原始偏好值用于核验完整操作身份，显示与编辑按卡片目录归并。
布局弹窗持有单独草稿，支持把手拖放及键盘排序、添加、移除和恢复默认；保存成功后才应用到概览。
该具体 UI 偏好文件仅允许固定字段，按实例、CAS修订和最后 operation 校验，原子替换；
未知格式保留原字节并拒绝覆盖。它不保存业务配置、运行计划、凭据或普通编辑草稿。

`ExecutionProgress` 只投影已受理冻结计划和实际执行阶段，不参与准入、业务结果或恢复决策。
当前活动列表与实时日志由只读 Control 接口提供；停止请求受理不表示进程已停止。
活动任务名称、选择和依赖来自受理计划；专项任务结果只呈现已收集的真实 observation，未收到的结果保持未知。
提交后的 attempt report 重新核对 run、journal、计划和证据，供运行中心及历史展示同一任务报告。
`RecordSummaryReader` 在同一 SQLite 读取快照聚合日期与账号，最多366天、200账号每页，
不把十万历史送往浏览器分组。精确测量、耗时下界和未知耗时分别统计。
记录深链按稳定 run ID 读取，退役历史不重新显示。
账号历史深链同时保留账号身份，刷新及尝试定位重新读取该账号的服务端历史事实，日志和图片沿冻结步骤归属过滤。
历史分别展示和筛选业务判定与运行生命周期；有账号身份的筛选及日期/账号汇总使用服务端条件。
脚本组视图沿稳定游标收集完整的一页无账号记录，不把某个服务端页中未匹配的记录当作筛选终点。
匹配记录前瞻决定下一页是否存在，末尾只有账号记录时不显示空的下一页。
记录列表呈现当前50项及必要选择，扩展徽章随窗口释放；最多缓存八页，每页序列化长度至多131,072字符，并保留最多32份游标书签。实例、权限、筛选及明确刷新清除原页；容量内回到已读页复用数据。
跳回已淘汰书签时从保留的较早游标重新读取，读取可取消，失败保留原窗口及页码。
运行被取消或中断后，已经收集的业务成功事实仍保留；界面同时显示该运行状态。历史统计明确标记业务判定口径。
单文件配置原件请求省略空相对路径，以资源文件名显示和识别 JSON、JSONC 或 YAML 语法。

## 公共控件与扩展

扩展生命周期通知携带扩展身份。指定扩展的挂载区保留其他扩展加载或退役时的界面与普通草稿，
在自身扩展退役、重新激活或挂载上下文改变时释放并重建。

设置页按服务、远程访问、代理、高级、更新和诊断分组；有效字段变更使用原设置修订自动保存。
普通草稿和原操作留在实例所属的 store owner，未知结果锁定后只能查询该操作；修订冲突不自动覆盖。
界面语言保存在独立界面偏好，宿主语言仍由 Host 设置控制。界面偏好读取携带最后保存的操作编号，
用于核对丢失响应后的原 CAS 结果；相同值和更高修订本身不构成原操作证明。
通用字段编辑通过宿主现有解析器读取当前保存的 JSON、JSONC 或 YAML 文档，核对修订和源摘要后定位字段。
数字对象键保留字符串，数组下标使用数字；解析失败时不生成猜测的 selector，也不发送字段修改。

页面使用分组侧栏、线条图标、双层页头、圆角卡片、列表与详情面板，以及带固定动作区的编辑弹窗。
普通草稿、权威命令、布局顺序和分类展开仍由各自状态 owner 管理；视觉布局不重排已保存的用户偏好。
旧版本只作为截图与交互参照，不复制其实现，也不参与当前构建。

应用内选择、日历、时间、颜色、数字步进和确认浮层由共享自绘控件承载。
`FormSelect`、`FormDate`、`FormNumber` 只适配 Vue 的模型和事件，继续使用同一控件 owner；不另建业务状态。
大型选择器使用80项呈现窗口，支持分页、搜索及跨窗口键盘访问。首次输入和输入法组合不清空查询。
日期范围由单入口双月浮层提供预览和应用；取消不提交，外部范围或边界变化撤销过期草稿。
相同值的消费者重绘不重建正在操作的日历。历史页应用完整范围后才重新查询。
分页使用有界数字按钮和首尾跳转；未知总数只展示已知页与下一页能力，不推断总量。
保存入口通过 `components/form-validation.ts` 提交可见数字控件并检查真实输入有效性；无效值聚焦并阻止写入。
浮层采用有界的 top layer、键盘导航、Escape 撤销与焦点恢复，卸载时释放。
日期范围内可用 Tab 继续操作；焦点移出控件才撤销未应用的预览。
文本输入保留语义元素、输入法与辅助功能；复选框、滑块、进度条、滚动条和展开标记使用明确绘制的外观。
系统文件选择、保存授权与浏览器关闭保护保留平台边界，不以自绘界面绕过授权。
异步确认只授权所显示的目标；插件映射或配置在等待中变化时，需要重新预览和确认。

`ui` 实现40个现役 `nexus-` 元素，属性/事件/slot由 SDK 生成元数据约束。
Vue 只进行属性、事件和可见性适配，不维护另一套控件权威。
`app/locale.ts` 提供响应式语言与显式页面词条，主题沿共享 CSS token。
`styles/theme.css` 拥有主题调色板与表面，`ui/theme.css` 只映射公开控件 token；次级表面随深浅和系统主题变化。
粒子由可见性和 reduced-motion 控制；页面隐藏不继续展示帧。
粒子按实际视口使用36/56/80档，颜色与透明度在外观变化时刷新；减少动态模式也重绘静态画面。

`FrontendRegistry` 在激活成功前暂存注册，失败撤回并清理；注册、停止通知挂载器更新。
`ExtensionOutlet` 将实例、实体、运行和尝试身份传入公开表面；插件独立路由沿同一导航准备流程。
`application.appearance` 常驻应用背景层，随窗口可见性通知插件，跨 Host 页面切换保持挂载。
该表面独占 `setAppearance`：仅接收固定的 HEX 配色、0–1 卡片不透明度与次级透明开关；清空或 scope 卸载还原 Host token，窗口隐藏保留配色。
表面在独立容器准备，以子 scope 拥有异步工作，卸载后晚到 cleanup 仍立即释放。
该机制是受信插件的生命周期边界，不是任意代码安全沙箱。

五个官方浏览器模块的独立业务端口与 fixture 归 Plugins 仓库。
这些结果只记 contract-only；生产服务适配、manifest接入和14插件完整整合属于P3。
公共控件 fixture、页面 smoke、人工视觉对照和完整进程族性能各自保留证据，不相互代替。

## 列表投影与草稿

账号摘要由 `/control/v1/automation/users/summary` 一次返回当前用户集合。
需要 automation.read、status.read、records.read、scheduling.read；权限不足不显示为尚未运行。
摘要按有效专项绑定的最近结果和最差 tone 聚合，区分无绑定、未运行、退役和无任务报告。
活动数量按实际 run/binding 去重；下次日程按有效 binding→script→queue、星期与时区批量选择。
页面共用请求与时钟，隐藏时取消，过期身份只触发一次刷新。

成功的队列保存、导入及删除只清理原 owner 的实体和 schedules 草稿；未知写结果保留原操作。
全局覆盖显示有效值并锁定对应组，保存仍保留绑定原字段。历史 decoder 一次验证 attempt 身份、顺序与有界游标。
任务 titleLocales 随计划和最终报告冻结；历史不使用后来安装的插件补文案。

插件 installed/store 分别保留筛选；名称索引仅在 metadata 更新时重算，支持 NFKC、全拼与首字母。
日期来自同源 catalog/manifest，缺失永远排后，不以打包时间或 catalog 总发布时间代替插件日期。
首页活动卡跟随真实 frontend 注册，布局可排序、隐藏和恢复。

## 架构与验证

`tooling/frontend_boundaries.mjs` 用 TS/Vue AST 检查 import/export、类型、alias 和字面动态 import。
SDK 不反向依赖 apps；control 不依赖 UI/页面；ui 不依赖业务、HTTP 或扩展装载器。
ui 只允许精确的纯 `control/identity.ts`；页面通过 `ExtensionOutlet.vue` 消费表面。
App.vue 是装载组合点，AppNavigation.vue 只允许 Registry 类型；没有整个 app 目录豁免。
按范围验证命令见 [前端测试入口](frontend-testing.md)。

桌面 profile/window-state.json 仅保存当前格式的有界 normal bounds 和最大化状态。
未知或损坏文件保留原字节，当前会话使用默认布局且不自动覆盖。位置保存共用一个 200 ms timer，
隐藏、释放及退出前 flush；显示器或 DPI 变化重新放入可见工作区。
最小业务区为1280×720，另含40 DIP标题区；低分辨率可选择继续、后台或取消。

设置分类按钮将卡片置顶，先绘制折叠状态，再运行展开动画；再次选择该置顶分类时收回并清除置顶。直接点击卡片标题展开或折叠时清除旧置顶，使用自然顺序；仅分类按钮可置顶展开项，已折叠卡片的历史置顶不参与布局。快速切换只展开最后选中的分类，保留各卡片草稿。分类切换保持分类栏在滚动视口中的位置，宿主与插件使用同一拥有者。

设置卡片以单一展开项和置顶项协调宿主及插件。插件表面的布局容器参与排序；公共折叠卡提供标题说明和双向高度动画，关闭立即禁用内容交互，减少动态效果时直接切换。所有公共 toast 由控件统一排在视口右下角，按实际高度向上堆叠。

脚本类型选择器随脚本页预加载目录，保留已加载卡片并在页面返回、弹窗打开和插件设置变更时刷新；首次加载整体呈现类型列表。每次新建先选择类型，各类型未保存草稿独立恢复，关闭编辑器不跳过下一次类型选择。

用户绑定卡片标题仅容纳拖动、图标、名称、状态与展开入口；编辑配置位于展开内容。脚本、账号、队列、通知与签到列表采用紧凑行距，图标、文字组与操作整体垂直居中，长内容换行时自然增高。

## 绑定卡片与操作反馈

绑定卡片使用双列布局，展开项占满一行，布局与内容折叠同时动画；收起的草稿保持但不可交互。排序由公共指针 owner 提供整卡位移与落点提示，仅在放手时提交，取消或集合变化不提交；键盘排序保留。

`nexus-toast` 使用手动 popover 进入浏览器顶层，模态层变化后重新排到最前，不抢焦点，不展示内部操作按钮。普通提示 4 秒、警告及错误 6 秒后向下淡出；动画服从主题时长和系统减少动态效果设置。提示消失不清理待确认写入，查询和重试保留在所属界面。插件公共面板的临时反馈也使用同一组件。

绑定脚本卡片展开后占整行并置顶，收起恢复原有排序，草稿留在原组件。排序禁用只限制拖拽和排序键，不禁用或淡化卡片内部编辑控件。

表单提交关闭浏览器原生提示，遍历可编辑且可见的控件并标记全部无效字段；统一顶层 toast 提示，修正字段后清除标记，不在输入框下插入错误文字。弹窗滚动内容自身提供尾部间距，滚至末尾时保留完整操作区；原生和公共控件的焦点描边位于边界内。

自绘滚动条仅在滚动期间及最后一次滚动后两秒显示，悬停或保持焦点不延长显示。Host 状态事件连接由请求取消和实时权限检查控制生命周期，空闲保持心跳，不因固定运行时长主动断线。

宿主提示错误码由 `app/error-messages.ts` 提供中英文解释，插件前端错误由共享 frontend-ui 的 TS 文案表处理；错误对象与操作编号保持原样，只在展示时翻译。未识别的 toast 错误码显示当前语言的失败说明并保留代码，切换语言更新现有提示。

## 通知编辑会话

通知页为每个实例及任务或新建渠道绑定编辑能力。编辑器持有草稿、修订、待确认操作和内存凭据，通过具名操作读取目录与凭据状态、按修订保存、测试已保存任务及查询原操作。通知页继续管理列表、删除和排序；编辑会话只访问自己的草稿和反馈。

| 验收 | 可观察结果 |
|---|---|
| 能力边界 | 编辑器、命令和凭据会话只消费绑定后的能力。TS/Vue AST 门禁拦截对 `AppStore` 及其宽端口的依赖。 |
| 保存与冲突 | 保存发送原目录和任务修订。冲突保留草稿，显式载入最新后可以按新修订保存。已保存任务可以测试；有未保存修改或权限不足时禁用对应操作。 |
| 结果待确认 | 保存或测试结果未知时保留原操作 ID，查询验证操作 ID 和类型。查询期间保留草稿，确认后结清原操作，写入与测试各只提交一次。 |
| 会话切换 | 关闭编辑器释放凭据及显式刷新读取，普通草稿仍可恢复。同一实例已发出的写入可结清其草稿；旧实例的迟到响应与错误保持在原会话。 |

使用真实通知页和编辑器、受控 Control 响应验证上述场景，并运行现役 Web 类型检查、依赖边界和生产构建。

## 按需详情与媒体释放

详情复用已读取最终报告，attempt 进入视口才加载日志和图片目录，原图由具体打开动作读取。
折叠日志不读取正文；目录按游标续页，固定行高窗口只挂载可见及少量前后缓冲。隐藏取消，切换身份重置。
日期总览与展开账号分别请求服务端日期/账号摘要，每页最多 200 个账号及一个前瞻项，保持时间范围、权限与退役过滤。
已加载数据随会话、权限和修订失效，缺失历史索引只重试未就绪资源。

当前语言的 ICU 格式化器在语言变化时更新，详情不重复创建原生格式数据；各入口的时长精度和日历日期语义保持。
原件弹窗在同一详情内复用，每次重置缩放与位置，隐藏取消并清空画布，详情结束销毁。
支持 WebCodecs 时每次可见绘制拥有独立解码器，绘制后关闭帧与解码器；其他环境使用 ImageBitmap 并及时关闭。
缩略图宽度按 64 像素分档；LiveScreenshot 预览最高 360 像素高，普通原图入口保持。

图片下载、编码缓存和解码准入分别服从[性能预算](performance.md#容量与超限)，最后引用消失即取消并释放 URL。
队列完成后仍需测量画布与 GPU 资源回落。可见粒子按原刷新节奏绘制，隐藏停止非必要展示，减少动态效果设置保持。
