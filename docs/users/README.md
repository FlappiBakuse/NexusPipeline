# 使用指南

NexusPipeline 0.18.0 面向 Windows 11 x64。桌面应用和浏览器使用同一业务界面。
本地 Test 候选用于验收；正式签名、插件来源和更新来源由发行者配置。
Test 候选的成功安装不代表正式发布渠道已经可用。

## 安装与首次启动

| 资产 | 用途 |
|---|---|
| Setup | 新目录安装，通过安装器维护安装及卸载 |
| Portable | 解压完整目录后启动，迁移时保留运行数据 |
| Update | 供维护流程核验和切换载荷，不能当作完整安装包覆盖 |

从可信来源取得一致版本的完整资产，放入新的可写目录，不混入其他候选的文件。
0.17→0.18 必须使用新目录和新实例，不导入旧运行数据。保留旧目录及配置，不能覆盖旧安装来绕过跨代屏障。
启动根目录的 `NexusPipeline.exe`；不带参数时使用同目录下的 `runtime` 目录。
首次启动创建实例，以后复用。未知格式或已初始化数据库丢失会拒绝启动，不以空库替代旧数据。
在设置页确认语言、主题、端口及窗口行为。开机自启动是明确的设置项，保存后检查结果。
关闭窗口、隐藏到托盘和退出服务不同；不要以窗口消失判断任务已经退出。
正常启动只补装从未安装的默认插件，不恢复用户卸载的插件或替换已有安装。
个人验收装配包含全部 14 插件，不改变正式预装范围。

## 脚本、账号与绑定

1. 登记脚本根目录和实际程序；专项发现后核对程序、资源、参数与目标。
2. 创建账号，组织各自的配置和执行选择；创建账号不等于已登录第三方服务。
3. 为账号绑定脚本，读取配置，再选择任务、运行限制、重试策略和通知。
4. 核对 PC 游戏程序或模拟器实例；占位路径不代表目标可运行。
5. 查看执行预演中的账号、任务、目标、资源和预算，再启用绑定并启动。

普通草稿与秘密字段分开保存。秘密使用保留、设置、清除三种操作，空输入不自动表示清除。
结果未知时查询原操作或重新读取状态，不重复发送写入。原生编辑需要本机授权。

## 队列、日程、重试与恢复

队列组织脚本选择和顺序，日程按保存时区及分钟规则触发。检查日程、绑定启用状态和预算。
资源冲突由原调度入口等待或报告，不另开第二个 Host 绕过独占。
普通失败按保存的重试次数在当前 attempt 内再次调用；中断后的新 attempt 还须满足安全声明与宿主批准。
两者都受原调用上限和总预算约束。
脚本失败后会清理脚本和游戏，下一次可能需要重新执行技术准备步骤；准备步骤不等于已完成的业务任务。
允许的中断后继保留原 run，并使用新 attempt。Host 进程重启后若无法证明预算连续，会以 `retry_budget_unknown` 拒绝自动续跑。
取消已受理不代表所有进程已退出，仍须回收进程和恢复配置。
未知外部副作用不自动重放。异常退出后从原实例启动；隔离或恢复失败先查诊断，不能删除锁或 journal 消除提示。

## 历史、日志与画面

历史按运行和尝试保留独立业务、生命周期结果，使用筛选和分页定位。
实时日志只驻留有界尾部，完整日志仍可分块读取或下载。图片可分页查看并打开原图。
内容退役有独立状态，不能当作读取成功。
启用 LiveScreenshot 后在当前执行详情查看画面。可见时每五秒采样，慢请求不重叠、不积压；
隐藏、结束或停用后停止展示请求。预览最高 360 像素高，历史原图保持原尺寸。
等待游戏、等待模拟器和暂不可用分别显示；采集时间来自 Host。它不是录像，也不任意截取桌面。

## 插件与通知

在插件中心核对来源、版本、兼容性及启用状态，再安装、更新、停用或卸载。
签名、摘要、内容或 SDK 指纹不匹配时停止处理，不改 manifest 绕过检查。
离线不代表已有安装失效，也不代表未下载的包已安装。正式信任尚未配置的候选不能访问正式商店。
通知先选择通道、保存专用凭据，再测试目标；一次成功不能代替触发规则、去重和失败诊断。
关闭通知不会撤回已发生的外部发送。

## 远端、CLI 与 MCP

Web 默认监听本机 IPv4 回环。远端访问须显式启用并配置 Bearer，使用实际地址与端口。
网卡地址列表不证明 NAT 或公网可达；秘密明文和原生动作仍受本机能力限制。
在装配目录执行，端口替换为实际端口：

```powershell
.\NexusPipeline.exe control menu --address http://127.0.0.1:58731
.\NexusPipeline.exe control status --address http://127.0.0.1:58731
```

菜单不启动服务，写入前确认，空行取消输入。MCP 使用独立回环监听，启用和写权限默认关闭。
能力及命令权威说明见 [控制面](../developer/control-http.md) 和 [管理菜单](../developer/cli-menu.md)。

## 诊断、更新与数据保全

记录版本、实例、失败操作身份及关联 ID，再查看诊断。支持包只含受限信息，不含全部日志或秘密。
更新的已受理、已交接、已完成表示不同阶段；完成后核对采用候选还是恢复原软件。
备份或迁移前正常退出完整进程族，保全整个运行目录，包括配置、数据库文件组、journal、blobs 和必要诊断。
不能只复制数据库而遗漏正在使用的 WAL，也不能在写入期间搬移目录。
卸载前核对数据保留选项和备份。应用载荷可重建，账号数据和失败证据不能随意删除。
未知格式、签名错误或恢复阻塞时保持原字节，提供最小复现信息。

账号摘要可打开对应运行历史；无运行记录时打开用户管理。开启全局同步的组显示全局有效设置，
关闭同步后仍可使用原独立设置。插件搜索支持中文、全拼和首字母；缺失日期不等于刚更新。
关闭编辑器保留普通草稿，明确取消才放弃；保存结果未知时先查询原操作。

历史按账号显示真实结果，详情中的日志和截图仅属于该账号的冻结步骤；同一次运行的内部重试另列实际调用次数。
队列可重复选择同一个脚本，执行顺序按保存的列表冻结。专项实例的启动与配置回写选项由插件声明约束。
