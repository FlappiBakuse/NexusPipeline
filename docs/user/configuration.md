# 管理账号配置

## 先分清三份内容

| 内容 | 作用 |
|---|---|
| 脚本原来的配置 | 软件开始本次运行或编辑前，脚本目录中真实存在的内容 |
| 账号已保存配置 | 该账号与脚本绑定的配置，供后续运行使用 |
| 本次运行中的配置 | 当前脚本正在使用和更新的内容，可能含进度、计数器或任务状态 |

运行结束恢复脚本原现场，并不意味着丢弃账号已经确认保存的更新。同一次普通失败重试继续使用本次运行中的进度，也不等于必须把这些变化长期保存。

## 第一次保存配置

如果绑定还没有保存配置，普通脚本首次运行会从已明确绑定的有效现场自动建立初始快照。已经有快照时不会因后续运行再次自动覆盖它。

## 编辑与取消

从账号绑定点击“编辑配置”即可打开脚本程序，MaaFramework 则打开内置编辑器。首次识别到多个独立配置时，先选择这个账号要编辑的一套。支持新建的脚本可以直接在程序里创建配置；需要初始配置的脚本会提示先完成设置。

编辑完成后回到 Host 保存。独立配置只能保留一套，出现多套时请在编辑器里移除多余配置。删掉原配置并仅保留一套新配置时，可以确认保存并更换绑定。绑定和新配置会同时生效，下次编辑和运行会使用保存的配置。通用脚本声明的多个文件和目录视为一套配置。

保存或取消均会等待编辑程序停止并恢复原安装目录。暂时关闭窗口后，可再次从“编辑配置”返回本次会话。

在账号绑定的“任务计划”中检查已保存的专项配置。应用修复前，先预览修改内容。诊断可能说明“当前配置不能运行”，并提供修复方法。修复受当前账号和受保护字段权限约束。

删除整个账号时，需要输入与显示名称完全一致的用户名。确认后会解除该账号的全部脚本绑定，并移除这些绑定的当前配置。

## 运行中的进度与长期同步

普通失败重试应接续上一调用的有效活动配置。例如脚本已写入检查点 1，下一调用应从 1 继续，而不是回到本次运行最初的 0。关闭自动保存长期配置，也不应取消同一运行内的进度接续。

自动同步按现有初次检查与运行结束流程执行。运行较短不等于结束时必然不保存；是否保存仍取决于绑定策略及输出有效性。专项声明要求结束回写时，界面应显示实际有效约束。

同步规则允许合法配置紧凑化；内容相同而字节变少不应单独导致拒绝。配置缺失、空内容、损坏，或目录文件数减少到已保存目录的一半及以下时，保留旧快照并说明原因。

同步失败需要可见诊断，但不能把失败说成已经保存成功。修复输入后再按明确操作处理，不通过反复运行来猜测配置是否入库。

## 草稿、秘密与未知结果

只有实际修改的表单才保留草稿。关闭、Escape、点击遮罩、切页或隐藏后，再次进入会恢复内容并提醒保存或取消；未编辑的表单关闭后重新读取已保存内容。查询、探测和预览保持父表单。

已有配置的草稿重新打开后，变化字段和开关显示黄色边框；首次编辑与新建配置使用普通边框，改回保存值后清除黄色状态。明确取消丢弃当前目标及所属子草稿，保存成功更新基线。保存失败、冲突或结果待确认时保留原内容和操作。

草稿仅属于当前界面会话。完整退出、页面重载及桌面/轻量模式切换后清空，退出没有草稿确认；退出失败仍可返回继续编辑。概览布局、活动和即时设置各自的保存边界见[快速开始](quickstart.md#界面设置)。

密码、令牌等秘密有“保留”“设置”“清除”的独立语义。空输入不自动表示删除。不要把秘密粘贴到日志、普通备注或问题截图。

保存结果未知时，先检查原操作与当前修订；确认后再继续。程序意外退出后的恢复与普通失败重试不同，见[排障](troubleshooting.md)与[队列和日程](schedules.md)。
