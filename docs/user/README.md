## 界面中的几个对象

**脚本实例**指一个实际程序及其配置位置；**账号**保存该用户的偏好与各脚本配置；**绑定**表示这个账号使用哪个脚本、哪些任务和运行限制；**队列**规定多个脚本选择的顺序；**日程**规定何时请求运行队列。

创建账号不会替你登录游戏或第三方网站。插件可能提供独立的凭据或网页登录入口，其成功与脚本能否执行分别确认。

“请求已受理”表示软件接到了操作，未必表示脚本完成。停止请求也需要等待程序退出和配置恢复。遇到“结果待确认”时，先查询原操作，不重复点击发送同一写入。

主导航使用“脚本库”“账号与配置”“计划与队列”“运行中心”“运行历史”“插件中心”“通知”和“设置”等实际名称。教程中的成功反馈以当前界面显示为准；内部错误码只用于进一步排障。
