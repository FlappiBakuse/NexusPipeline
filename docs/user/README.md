# 用户指南（v0.16.9 本地开发版）

正式下载地址与已发布版本以 [Releases](https://github.com/FlappiBakuse/NexusPipeline/releases) 为准。本页说明当前源码实现的操作方式；隔离安装、旧版升级及真实游戏验收尚需对应环境验证。

## 安装和依赖

首次安装可选安装器或便携 ZIP。两者的初始应用文件来自同一份载荷：`nexus-pipeline.exe`、`wwwroot/`、`plugins/` 和 `README.md`。预装的 EmulatorSupport、LiveScreenshot 默认禁用，需要时再在插件页启用。安装器选择本地空目录；已登记且身份匹配的同一用户实例可选择原目录升级。它不会迁移或接管不明便携目录。便携包请解压到空目录，不要覆盖旧实例。

程序需要 .NET Desktop Runtime 8 x64 和 ASP.NET Core Runtime 8 x64。安装器在缺少依赖时会逐项询问并从固定微软地址下载校验后的包。便携版保留 .NET 的缺运行时提示，两个准确下载按钮见可离线打开的 [`wwwroot/help/runtime-prerequisites.html`](../../frontend/public/help/runtime-prerequisites.html)。安装 .NET 依赖可能需要系统授权；取消后可重新运行安装器。

## 运行、取消和日志

在「调度中心」启动脚本或队列。点击取消后，当前运行停止接纳后续派发与重试；宿主请求停止本次拥有的进程，并在配置写入者退出后恢复配置。停止请求和进程退出可能不是同一时刻。若进程或配置恢复失败，保留现场并查看运行历史和诊断，不要手工清空 `data/` 中的恢复工作区。

当前日志按用户、队列运行和尝试分段。切换用户或重试后，请在当前段查看新的 stdout、stderr 或文件日志；历史段仍可在历史详情查看。启动就绪与无日志超时分别计时。程序窗口存在不表示 stdout 已有业务进展；无新增输出到达超时会结束尝试，并在清理确认后才评估安全重试。

## 结果和重试

「流程已结束 · 有未核验项」表示进程已结束，但至少一项任务缺少足够业务证据。它不表示任务成功。任务详情中的“已满足的跳过”需要插件给出本轮证据；仅凭配置勾选或通用完成横幅不会当作领取成功。

选择重试只针对插件和宿主共同证明独立、安全、未成功的项目。已成功项目、身份不清的项目以及关机、重启等高风险收尾动作不会被扩大重跑。若诊断提示动作会影响后续队列，请先检查队列与上游配置；宿主不会自动改写这些动作。

官方 OK 系列新发行在安装身份、入口和基础配置可确认时可受限运行：保留启动、取消、超时、历史，但旧版高级结果规则和选择重试关闭。更新或修复中、来源不可信、基础配置不适用时会显示具体阻断原因。受限运行后的正常进程退出仍显示未核验。

## 配置修复

「允许配置修复」默认关闭。开启后，只对页面展示的具体修复建议先预览，再逐次点击应用；预览令牌绑定当前用户、脚本、配置快照和文件字节。文件变化或有运行/编辑冲突时需重新预览。该功能只允许已实现的窄范围修复，不代表任意插件配置可自动修正。

## 升级、卸载与恢复

升级前退出程序并备份当前实例完整目录，至少包括 `config/`、`data/`、`history/`、`logs/`、`plugins/` 和 `.nxp/`。内置更新保留用户目录；v0.16.8 的旧 worker 只交换 EXE 与 `wwwroot/`，v0.16.9 首次启动仅在 README 缺失时从已暂存包补齐。手动升级只替换 `nexus-pipeline.exe`、`wwwroot/` 和 `README.md`，不要覆盖用户的 `plugins/`。不明旧目录不能通过安装器就地接管。

卸载默认保留用户数据。只有在卸载向导中明确勾选“删除此实例用户数据”后，才尝试删除已确认归属此实例的固定目录；链接、未知文件、外部游戏或脚本路径保留。.NET 依赖不会随本程序卸载。若安装、更新或卸载提示待恢复 journal、备份、文件锁或剩余文件，请保留现场并按 [恢复说明](../architecture/recovery.md)排查。

## 常见问题

**为何结束后不是成功？** 查看任务详情的未核验原因和本次日志段；上游没有独立确认时，宿主不能推断成功。

**为何新官方版本只有受限模式？** 高级判定需要该发行的配置与日志契约证据；基础启动可确认时仍可运行，结果保持未核验。

**为何安装器拒绝旧目录？** 它只接受空目录或当前 Windows 用户已登记的实例，避免覆盖未知便携安装及用户数据。旧便携实例可用内置更新或按上方手动步骤升级。

**为何配置修复按钮不能应用？** 检查开关、预览令牌、当前文件是否变化，以及是否有运行或配置事务占用；确认后重新预览。

**能否用真实账号测试？** 本地自动化验收不包含真实账号、游戏、设备或机器人；这些验证应在独立授权的环境进行。
