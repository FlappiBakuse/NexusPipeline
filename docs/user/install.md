# 安装与启动

当前目标版本的待验证与发行范围见[状态表](../status.md)。下载来源以实际发行渠道为准。

## 选择正确的包

NexusPipeline 0.18 的目标环境是 Windows 11 x64。使用发行者提供的同一版本完整包；开发验收包与正式包的权限和信任配置可能不同，不混用文件。

| 包 | 用途 | 使用方式 |
|---|---|---|
| Setup | 新目录安装与安装器管理 | 按安装器选择目录及快捷方式 |
| Portable | 解压后使用完整应用目录 | 保留整个解压目录，按包内说明打开 GUI 入口 |
| Update | 已有受支持实例的维护更新 | 交给应用的更新流程，不作为完整安装包覆盖 |

程序需要的 .NET 运行时版本由当前安装包决定；使用 Setup 时按安装器提示处理。不要用某篇旧教程中的依赖版本替换当前包要求。

Setup 在安装临时区准备默认插件，Portable 在首次启动消费一次性输入，成功后清理。已安装插件统一由 `runtime/extensions` 管理，应用更新和保留数据重装保留插件选择。[插件管理](plugins.md)

## 从 0.17 开始使用 0.18

1. 正常退出旧版服务、桌面和正在运行的任务，保留整个旧目录。
2. 将 0.18 安装或解压到新的空目录，创建新实例。
3. 通过界面重新登记脚本、账号和配置，再做第一次运行。
4. 旧账号数据和历史继续由保留的旧版本读取。不要把旧运行目录、插件或数据库直接复制到新实例。

0.18 没有承诺 0.17 运行数据自动迁移；跨代更新不能通过手工覆盖应用目录绕过。

## 打开客户端

使用安装快捷方式或双击应用根目录 `NexusPipeline.exe` 启动。该入口也接受命令行参数；已有 Launcher 快捷方式仍可使用。

默认无参数启动使用应用目录下的 `runtime`。如果你使用显式指定运行目录的方式，后续始终使用同一目录；不要因界面暂未出现就改到另一个空目录。

桌面主窗口中央显示真实启动阶段和已用时间，完成后原位显示控制台。启动期间关闭窗口会隐藏至托盘，恢复继续且就绪后保持隐藏。轻量模式只显示托盘，完成后打开默认浏览器。

## 窗口与开机运行

在“设置”中选择启动时是否显示窗口及“开机自启”，选择完成后即时提交并显示实际登记状态；需要重启的选项会显示原因。隐藏启动保留隐藏意图。

新安装快捷方式和重新创建的自启项使用 GUI launcher；既有快捷方式或自启项不会因复制新文件自动改写。需要迁移时在应用中重新登记，并确认旧项已按原身份处理。

关闭窗口、隐藏到托盘与退出服务是不同操作。备份、搬移目录或安装更新前，使用正常退出流程并等待任务与服务停止。[备份与恢复](backup.md)说明需要保留的内容。

若启动失败或长时间停留，按[启动排障](troubleshooting.md)记录阶段与错误，不删除运行目录来“重新初始化”。
