# 查看运行历史、日志与截图

> 本地候选操作说明；当前统一验证状态见[状态表](../status.md)。

## 找到正确的记录

从“运行历史”选择账号、脚本或组合范围，再按结果与时间定位。需要下一批时翻页；筛选应由同一查询条件持续生效，不能因为当前一页没有匹配项就断言后面也没有。

账号摘要进入历史后，应保持该账号身份。打开、刷新页面或复制链接给同一实例的另一客户端，仍应看到这个账号的结果、步骤、日志和图片。整体队列入口则可以查看全部账号。


## 读懂结果

业务结果回答任务是否完成；生命周期说明运行是否结束、取消、中断或被阻止；配置恢复状态说明原现场是否已恢复。查看失败时应同时看原因和恢复状态，不能只根据进程退出或按钮颜色判断。

同一运行中的普通失败重试有实际调用次数。意外中断后若获准继续，会保留原运行下的后继尝试与旧证据，历史不应把它们合成一次从未中断的成功。

“未知”或“未验证”说明没有足够的相应证据，不能当作成功。已经保存的历史名称与任务说明不应因当前配置改名、插件停用或卸载而被重新解释。

## 日志

在对应账号和调用中查看日志来源，例如主任务、前置操作或后置操作。实时视图保留有限尾部；需要完整内容时使用分块读取或下载入口。切换调用后，日志和截图都应随同切换。

日志未可用、已退役和空日志是不同状态。已退役内容不应返回假成功；也不应为了补一个展示行而重新执行原任务。

## 图片和实时画面

历史图片按记录查看，可打开原图。LiveScreenshot 提供当前运行的实时预览；页面隐藏、运行结束或插件停用后停止展示请求。它不是录像，也不表示能够截取任意桌面窗口。

等待游戏、等待模拟器、采集失败和暂不可用应有对应状态。截图的时间与归属以 Host 记录为准，不用浏览器收到图片的时间替代采集事实。

## 大历史与保留

大量历史的第一页应按筛选分页读取，不应先下载全部记录。索引补齐若尚未完成，应显示当前准备状态，不能把暂时未投影的内容当作从未运行。

保留天数和内容清理会影响可见历史与可读取附件；涉及活动任务、待恢复配置或待通知引用的内容不能被提前清掉。需要长期保留时先按[备份流程](backup.md)保存完整运行目录。

报告问题时提供筛选条件、账号/运行身份、预期与实际结果，以及最小必要日志，不附凭据或完整私人配置。
