# 按症状排障

先记录操作、软件/插件版本、阶段、错误和原操作身份。已知待验证事项见[状态表](../status.md)。

| 症状 | 先检查 | 下一步 |
|---|---|---|
| 启动慢或没有界面 | 根 GUI 入口、托盘与当前阶段 | 保留阶段/错误，只运行一个 Host；不清空 runtime |
| 数据库准入失败 | 完整八库、伴随日志、磁盘空间及目录占用 | 保留现场；旧 nexus.db 使用新目录安装，缺库从完整备份恢复 |
| 深目录诊断副本报 SQLite error 14 | 本次错误、目录和构建身份 | 保留原路径与最小诊断，按[已知问题](../status.md)定位 |
| 选根后不能保存脚本 | 程序、专项插件、来源候选是否属于当前目录 | 多候选明确选择，缺失来源按诊断处理 |
| 提示缺配置 | 绑定、原配置、资源声明与快照 | 可主动读取；通用首跑自动建立失败时保留原因，不建空快照 |
| 探测后编辑器意外关闭 | 操作是否误触保存，已保存值和草稿 | 停止重复操作，记录最小步骤与结果 |
| 资源不可用 | 该操作对应文件、目录或插件是否存在且可读 | 修复明确资源，再执行对应操作 |
| 保存或运行结果待确认 | 原操作受理/完成状态 | 查询原操作，保留身份和输入 |
| 登录窗口加载失败 | 平台、阶段、网络/代理和错误码 | 在原窗口刷新、验证或取消；保留普通草稿 |
| 账号历史范围错误 | 链接中的账号与筛选身份 | 显式按账号核对，记录 run 与跳转步骤 |
| 组合历史查询慢 | 筛选条件与历史规模 | 按原游标等待，保留耗时；未完成查询下推见状态表 |
| 取消后仍恢复中 | 进程实际停止和配置还原状态 | 等待或查看恢复原因；保留 journal 与 writer 记录 |
| 插件或应用更新拒绝 | 包版本、来源、摘要和信任 | 使用配套完整包，不手改清单或信任绕过 |

## 启动诊断

确认没有另一个 Host 使用该实例，在实际应用目录执行；将示例路径换为原运行目录：

```powershell
.\NexusPipeline.exe serve --runtime-root 'D:\NexusData\runtime' --port saved
```

该命令保持原实例用于诊断。服务启动和查询详见[控制面](../reference/control-http.md)。

## 提供材料

提供软件/插件版本、构建或提交身份、最小操作步骤、预期/实际结果、错误码及关联 ID。日志只截取相关部分并移除秘密和个人资料。支持包包含受限诊断，范围见[诊断与支持材料](../operations/diagnostics.md)。

同一错误先按输入、权限、资源、未知结果或程序故障定位，再处理直接原因。用户配置、账号数据和恢复现场保持原字节。
