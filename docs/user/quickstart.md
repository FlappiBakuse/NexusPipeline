# 第一次运行

## 操作前准备

准备脚本的真实安装目录、实际程序和该账号原本使用的配置。如果脚本需要游戏或模拟器，先确认对应程序或实例能够正常打开。专项脚本还需要它对应的官方插件处于可用状态。

第一次不必先建立复杂日程。先完成一个账号、一个绑定的一次运行，确认配置、目标与结果，再加入队列。

## 1. 在脚本库登记脚本

打开“脚本库”，选择“新建脚本实例”，填写名称并选择实际根目录。专项类型根据已安装插件选择；通用脚本的主程序、启动参数、配置与日志路径在 Host 确认根目录实际存在后启用，再填写实际程序和路径。

选定专项根目录会自动读取并采用首个可用候选。核对实际程序、配置、任务与目标；换目录后重新核对当前结果。

桌面版在当前编辑窗口内记住上一次选择的文件夹。选择文件后记住文件所在文件夹。关闭该窗口后，新窗口从“文档”打开文件选择器。

脚本卡片显示脚本类型、启用的游戏启动方式和完成判定。日志无更新上限设为 `0` 时，卡片显示“长时策略”。

## 2. 创建账号并绑定脚本

打开“账号与配置”，添加账号，选择刚建立的脚本绑定。核对执行任务、游戏或模拟器目标、运行顺序与限制。创建账号只建立本地配置归属，不会自动登录第三方服务。

启用全局设置同步时，界面显示当前有效的全局值；需要独立设置时关闭相应同步，再编辑该账号自己的值。不要把被继承锁定的显示值当作可以直接覆盖的本地草稿。

## 3. 建立并检查配置

没有保存快照时，普通脚本首次运行会从已绑定、可验证的原配置建立初始快照。已有专项配置的任务选择可在绑定下方的“任务计划”中查看。遇到来源不完整、被占用或无法核实的提示时，先解决来源问题。

从绑定的“编辑配置”进入，确认将打开的程序与账号。新绑定可先保留配置草稿，再随账号窗口一起保存。放弃更改时取消编辑并等待恢复。[配置管理](configuration.md)解释运行中进度与长期保存的区别。


## 4. 预览本次运行

打开“运行中心”，选择脚本实例或调度队列，再点击“检查运行计划”。从上到下查看脚本组的运行顺序，每组内按序号核对账号和可运行、将跳过或无法运行的状态。队列设置的前置成功条件显示在对应组上方。预览本身不执行任务，也不修改配置。

并行运行时，从顶部的任务标签切换队列步骤、专项任务、实时日志及可用画面。手机端可横向滑动标签并查看单路详情。宽屏有两项或更多活动运行时，可开启双路分屏。待核对的运行会在标签上方提示。

如果计划提示缺失配置或资源，返回对应绑定修复；预览变化后重新确认。不要通过切换到另一个实例来绕开当前占用或恢复提示。

## 5. 开始并观察

点击“执行脚本”或“执行队列”可直接提交运行。未有活动任务时，空状态卡片居中显示提交和受理状态。运行开始后，在“运行中”查看实际状态和日志。请求取消后，卡片会显示停止和配置恢复进度。需要核对运行时，打开“设置 → 系统诊断”，先看优先处理项和对应的下一步，再按需展开检查明细。核对完成后再搬移目录。

如果保存或运行请求显示“结果待确认”，使用“查询操作状态”核实原操作。不要反复点开始来补偿一次网络超时。

## 6. 核对结果

从账号摘要或“运行历史”打开刚才的记录，确认该账号的业务结果、实际调用次数、日志与截图。展开“脚本日志”可在详情卡片内查看完整的已归档日志，长行会自动换行。专项任务会显示已满足、不适用、未安排核验、未执行或结果未保存等状态。选中的已识别任务缺少日志或终态时，可在失败任务旁查看原因。

这次运行符合预期后，再在“计划与队列”添加顺序和日程。相关步骤见[队列与日程](schedules.md)。

## 界面设置

宿主设置填写或选择完成后即时生效，需要重启的选项显示原因。自定义壁纸的选择、排序与效果同样即时保存。

“今日概览 → 编辑页面布局”中的显示卡片和可添加卡片均可通过把手拖放或键盘排序。添加、移除、排序和恢复默认立即预览；点击保存保留当前布局，关闭或取消恢复已保存布局。

游戏活动的订阅、内容进度、顺序和轮播设置在点击保存后生效；关闭或取消丢弃本次编辑。完整规则见[设置保存边界](../reference/settings.md#即时设置与界面偏好)。

普通配置编辑保留实际修改的草稿，恢复提醒与退出清理规则见[管理账号配置](configuration.md#草稿秘密与未知结果)。
