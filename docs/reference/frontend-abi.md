# 前端公共元素与扩展表面

`contracts/ui-elements.json` 引用 40 个独立元素定义，生成 SDK 的属性、事件与运行时元数据。
结构化值只通过 property 传递；程序设置不派发用户 change。
公开名称使用 `nexus-`，不注册旧元素别名。

当前 Native Custom Elements 覆盖台账中全部40项输入、操作、结构与反馈元素。
它们共享主题变量，通过标准 slot 保留消费者节点；交互元素的 `focus()` 进入实际控件。
密码 value 只驻留 property 和表单输入，不反射为 attribute 或表单恢复状态。
宿主 Vue 通过 property、事件、slot和显式可见性消费同一实现；应用归属见 [Web 前端](../architecture/frontend.md)。

## 输入、帮助与校验

数字控件在标准 `aria-invalid` 上公开无效状态，保留未通过校验的原始文本；有效修正才更新 value 与 change。
数字控件支持 `placeholder` 字符串，空值时显示；`FormNumber` 转发同一属性，已有数值保持显示。
`nexus-tooltip` 在字段旁绘制问号按钮。点击、Enter 或 Space 可开关，Escape 或点击外部可关闭。带小三角的气泡优先在问号上方展开，空间不足时可放在整个字段下方，填写和选择区域始终可用。
非字段锚点可通过悬停或键盘聚焦显示补充信息，默认延迟 400ms。气泡保留当前焦点。常见操作保留按钮的可访问名称，省去重复名称的气泡。
描述节点与锚点同根，内部控件可引用祖先根；更新内容保留已有错误描述，隐藏、移除和卸载清理临时状态。
锚点选择框展开时立即关闭帮助；选择框收起后可重新打开，输入始终保有可访问描述。
Host 字段使用 `v-help`，插件通过 frontend-ui 的 `fieldHelp` 使用同一个组件。字段问号与标签文字垂直居中。开关卡片在标题下显示完整的 `description`。帮助内容只接受文本。
`nexus-switch-list` 为直接放入的 `nexus-switch-setting` 绘制统一外框，并在相邻的可见开关之间绘制分隔线。
页面卡片与弹窗底板使用 `--content-card`，内嵌卡片使用颜色较浅的 `--content-card-soft`，其中的 `--content-control` 回到较深的底板色。自绘内嵌区块声明 `data-surface="raised"` 即可加入同一层级；标准控件经继承获取对应颜色。深浅主题和壁纸透明度均由宿主统一解析。

内嵌区块中的开关列表和空状态沿用区块的控件底色，与外层区块形成深浅对比。列表的标题、内容和行分隔线共用同一底色。

展开卡片由 `nexus-collapsible-card` 或声明 `data-surface="collapsible"` 的外层统一着色，标题和展开内容共用底色。主页面的展开卡片使用深色底板，二级弹窗中的展开卡片使用浅色底板；内部独立区块与控件继承相应的深浅层级。
页面和弹窗使用顶层 Toast 呈现操作结果及提醒。首次安装随附插件时的 Toast 持续到插件就绪；重开未保存的草稿时显示一次 Toast，并保留已修改字段的高亮。
文件选择器显示操作文字及文件名，标准必填文本同时参与表单有效性；选择器忽略锚点未移动的延迟滚动事件。
`nexus-path-picker.disabled` 同时禁用文本、浏览按钮及变更事件。组合输入的焦点和错误描边覆盖整个控件及附属按钮。
字段保留原生 `required`、类型与范围约束；空 `title` 边界阻断 Chromium 将 `validationMessage` 用作悬停提示的回退，`invalid` 事件取消原生提交气泡。
帮助使用 `nexus-tooltip`，组件标题保留在属性值中并移除会触发原生提示的 HTML `title`。原生输入自身的空 `title` 同时覆盖键盘焦点提示。
保存入口通过 `components/form-validation.ts` 提交可见数字控件并检查真实输入有效性；遍历可编辑且可见的字段，标记全部无效项并聚焦首项，统一 toast 提示。修正后清除标记，不在字段下插入错误文字。
`nexus-range` 拖动时不绘制焦点高亮框，键盘聚焦保留可见提示。

## 选择与临时状态

`FormSelect`、`FormDate`、`FormNumber` 只适配 Vue 模型、事件及可见性，共用公共控件 owner。
大型选择器使用80项呈现窗口，支持分页、搜索及跨窗口键盘访问；首次输入和输入法组合不清空查询。
日期范围使用单入口双月浮层预览和应用；取消不提交，外部范围或边界变化撤销过期预览。相同值重绘保留正在操作的日历；历史页只在应用完整范围后查询。
浮层使用有界顶层、键盘导航、Escape 撤销与焦点恢复，卸载释放。日期范围内可用 Tab 继续操作，焦点移出后撤销未应用预览。
分页使用有界数字按钮和首尾跳转；未知总数只展示已知页与下一页能力。
排序取消、身份集合变化或禁用时不提交重排；禁用排序不限制卡片内部的其他编辑操作。

## 结构与反馈

图标按钮将标准 `aria-pressed` 同步至内部按钮，图标 slot 不拦截指针操作。
模态使用显式视口宽度及自绘样式，移动端操作按钮为44px，输入框与步进按钮按各自尺寸呈现。
`--nx-modal-title-size` 与 `--nx-modal-title-line-height` 用于具体表面的标题层级，`--nx-action-height` 只控制操作按钮。
`--nx-button-fill` 调整中性操作按钮的表面，`--nx-drag-size` 调整拖拽把手的触控区域。
`--nx-button-padding`、`--nx-button-radius` 与输入字体、内边距变量调整消费者外观，不改变元素属性或事件合同。
`nexus-empty-state` 默认最小高度147px，标题15px/700、说明13px/400；宿主和插件空列表共用同一元素。
`nexus-toast` 使用手动 popover 进入顶层，模态层变化后重新排到最前，不抢焦点；按实际高度排在右下角，不提供内部操作按钮。普通提示4秒、警告及错误6秒后淡出，动画服从主题和减少动态效果。提示消失不清理待确认写入，查询与重试留在所属界面。
弹窗滚动内容提供尾部间距，滚至末尾保留完整操作区；原生和公共控件的焦点描边位于边界内。
自绘滚动条只在滚动期间及最后滚动后两秒显示，悬停或保持焦点不延长显示。
模态将遮罩淡入和面板缩放分开计时；面板退出完成后才释放原生顶层，隐藏或卸载则立即释放。
导航扩展拥有完整页头与正文；宿主保留隐藏的核心页头目标供已访问核心页面使用，避免重复显示标题。

## 扩展挂载与安全

插件中心在720px以下以列表/详情两种视图呈现。已验证的安装详情同时返回安装修订与原归档摘要，
用于区别 develop 的同版本不同内容更新；稳定通道不把同版本归档差异作为升级。
发行 Markdown 由 [Marked](https://marked.js.org/) 编译，再由 [DOMPurify](https://github.com/cure53/DOMPurify) 清理；
正文不能注入表单、脚本、样式或宿主标识，外部链接仅允许 HTTP/HTTPS。
安装与设置命令在发送前保留完整原始正文；未知结果只读取原操作，不自动重放安装或运行激活。

SDK 的 `ExtensionScope` 拥有资源及子 scope；先 abort，再逆序释放，晚到 cleanup 立即执行。
前端注册表在 activate 完成前暂存 surface、route 和样式，成功后一并公布。
失败或停止时撤销所有注册及样式，并释放已挂载表面的子 scope。
表面先在断开的独立容器准备；取消后晚到代码只能持有已撤离的容器。
注册表是受信扩展的生命周期边界，不是浏览器脚本安全沙箱。
激活上下文的 `locale` 返回当前语言，`onLocaleChanged` 在原表面拥有期内通知语言变化；导航标签可使用 getter。
语言切换只更新文案，保留普通输入节点、原始无效文本和焦点。公共元素同样观察文档语言，秘密仍按可见性及会话拥有权清理。

`tests/frontend` 的原生浏览器 fixture 覆盖属性、事件、slot、主题、焦点、输入法、弹窗及整体回滚。
测试通过公共 SDK 消费同一组件源码，运行结果与完整产品集成证据分开登记。
测试驱动使用 [Electron 输入接口](https://www.electronjs.org/docs/latest/api/web-contents) 与
[Chromium Input 协议](https://chromedevtools.github.io/devtools-protocol/tot/Input/)，不把合成 DOM 键盘事件当作实际输入法证据。
