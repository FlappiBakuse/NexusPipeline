# ADR-0166-001：公共 UI 与测试治理收口

状态：Accepted（v0.16.6 开发中）

## 决定

宿主继续使用 Vue 3 + TypeScript + Vite。通用动作、字段、实体行、日期范围和排序职责集中在 `frontend/src/ui`，通过 `register.ts` 暴露给官方插件；业务数据、请求、保存和领域专属视图留在 features 或插件自身。Frontend API 保持 1.5，使用新公共元件的官方插件将最低宿主版本设为 0.16.6。

测试使用本地 registry、逻辑组和五个固定 Qualification Gate。PR Feedback 可以按四个粗粒度范围选择；最终 Qualification 不读取 diff。runner 对空测试、超时残留、原生报告缺失和失败/跳过做显式失败处理。功能测试放在最低有效层，UI Smoke 保留用户可观察流程，CSS/像素/截图检查进入架构治理或临时验证。

持久化继续采用当前格式策略。原子写入、损坏文件保全、配置交换资源释放和 Windows 进程边界属于现役可靠性机制；跨版本迁移、旧 API alias 和双格式解析不在本决定范围内。

## 依据与验证

实现入口为 `frontend/src/ui/register.ts`、`frontend/src/ui/composites`、`tools/frontend-boundaries.mjs`、`tests/registry.mjs`、`tests/run.mjs`。验证入口为 `frontend`、`bridge`、`config`、`persistence`、`plugins` 分组及对应 System smoke；官方插件执行 `npm run typecheck:frontend`、`npm run build:frontend` 和 `node tools/Test-FrontendPlugins.mjs`。
