# 秘密准备的独立恢复类型

Secrets 的加密候选不属于定义资产导入；其引用 CAS、DPAPI 绑定、重放校验及旧密文退役由 Secrets 拥有。
`secretPrepare` 扩展共同 journal 的类型集合，使用独立 `nexus.secret.preparation-plan`/1 与收据格式。
类型对应 prepared → applying → applied → committed 的单次效果门禁，不提供自动重写候选或回滚已公开秘密的路径。

接受事务保存原操作身份、HMAC 校验、候选 metadata、实际 creator 及 file outbox。
最终事务同时提交字段修订、原操作结果、旧引用清理意图及终态投影；密文和原生收据须已完整验证并保持只读句柄。
无效果取消要求旧 writer 已停止、门禁未进入和候选/收据确实缺失；其 operationId 不会被下一次新秘密值复用。
完整候选的恢复只补齐引用事务；部分或未知现场保持隔离，未知 committed 事实只读拒绝。
闭合历史依赖已持久化重放校验，不要求后来退役的密文继续存在。

原六类与资产准备的历史证据保留原范围；秘密准备另以真实 creator 强杀、原生停止、诊断副本预检和重复启动恢复验证。
Host 0.18.0、SDK 0.1.0 及插件 0.5.0 的未发布目标保持固定，以源码、契约和包摘要区分构建批次。
