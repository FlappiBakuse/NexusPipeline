# 历史索引

本目录只保存已发布版本的历史说明。当前产品行为、代码定位和未完成验证分别以[架构索引](../architecture/README.md)、代码与 [STATUS.md](../STATUS.md) 为准；架构取舍的理由单独记录在[决策索引](../decisions/README.md)。

| 范围 | 内容 |
|---|---|
| 当前系列：v0.17.X | [CHANGELOG.md](../../CHANGELOG.md) 的发布记录 |
| 上一系列：v0.16.X | [changelog-earlier.md](changelog-earlier.md) |

更新日志只维护最近两个已发布的 `major.minor` 系列。新增下一系列的首个发布记录时，原当前系列完整移入 `changelog-earlier.md`，新系列进入根 `CHANGELOG.md`，删除更旧系列的文档记录并更新本索引。发布前核对保留版本的记录完整性、排序和链接；Git 历史、GitHub Releases、更新屏障及插件发行记录各按原有规则维护。

固定提交链接继续按其声明的 commit 验证。历史文档中的旧编号和旧路径属于当时版本事实，不参与当前专题导航。
