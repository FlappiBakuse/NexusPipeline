# 0.18.0 目标说明

主程序与正式插件统一使用界面会话内存草稿：关闭、切页和隐藏后重开恢复，显式取消丢弃，保存失败保留原修订及操作编号。密码和 Token 单独保存在内存中，重开默认遮罩。退出、重载和模式切换清空草稿且不弹出草稿确认；实际写入和资源停止继续由原退出许可保护。托盘退出等待期间仍可唤回窗口和打开菜单，超时或失败后恢复操作。

状态：未正式发行。Host 0.18.0、SDK 0.1.0、官方插件 0.5.0 保持固定。
新的实例、状态与交换格式不兼容0.17运行数据；在新目录安装，保全旧目录，不迁移、不覆盖。
新实例按自动化、配置、运行、记录、通知、扩展、系统和内容登记分为八个业务库，跨库保存保持原子提交。
发现旧 `nexus.db` 时提示新目录安装，缺库及初始化中断保留现场；现有账号、配置和历史证据保持原样。
旧发现地址的更新屏障及公开发布顺序由发布流程维护，不能用本地候选代替正式渠道。

前端恢复队列连续编辑、账号聚合摘要、插件搜索与日期排序、窗口偏好；未知写结果继续保留原操作。
专项任务、诊断和包列表文本来自同一 i18n 源，任务语言随运行冻结。MaaEnd/MaaS 为纯数据专项，
调用已安装上游，不要求通用 Maa 插件，也不随专项分发 native/runtime/worker/compiler/provider/frontend。
通用 MaaFramework managed 插件继续独立拥有其框架执行能力。

运行中心任务启动保持卡片宽度，内部重试与恢复前调用计入次数；可见日志合并刷新，粒子保持显示刷新率。
活动执行在受保护拥有期内复用历史、计划与不可变解码，数据库连接保留页缓存，后台扫描按真实变化和有界预算推进。
连接和页缓存按实例共同限额，缓存按业务库失效；同步发布共享路径与 journal 输入，新修订增量处理。
插件旧工作树支持已开始删除后的中断续做，现役载荷与共享引用继续保护；配置运行历史按页核验，完成历史不占用活动容量。
资源目标及未完成项分别见[性能预算](../developer/performance.md)和[当前状态](../status.md)，实际指标保存在对应仓外验收报告。
