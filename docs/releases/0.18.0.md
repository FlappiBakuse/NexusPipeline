# 0.18.0 目标说明

状态：未正式发行。Host 0.18.0、SDK 0.1.0、官方插件 0.5.0 保持固定。当前待验证与待发布事项见[状态](../status.md)。

## 数据与运行

新实例按自动化、配置、运行、记录、通知、扩展、系统和内容登记拆为八库，跨业务保存保持原子提交。0.17→0.18 使用新目录、新实例，旧数据库、账号配置和历史证据保留。[安装](../user/install.md) · [备份](../user/backup.md) · [存储格式](../developer/storage.md)

执行期复用受保护的计划、journal 前缀与历史投影；连接和页缓存共享实例预算，缓存按业务库失效。后台工作沿事件、提交与到期推进，日志和截图按增量处理。[执行读取](../developer/execution.md#活动执行读取) · [性能口径](../developer/performance.md) · [逐库诊断](../developer/diagnostics.md)

## 编辑与桌面

实际修改的编辑草稿驻留界面会话内存，关闭后重开恢复；未编辑的表单关闭后释放。恢复草稿显示保存或取消提醒，已有对象的变化字段使用黄色状态。完整退出、重载和模式切换结束草稿会话。[配置操作](../user/configuration.md#草稿秘密与未知结果) · [编辑生命周期](../developer/frontend-state.md#编辑草稿)

概览布局、活动、宿主设置及自定义壁纸即时提交；布局和活动弹窗取消还原打开前的设置，保存与关闭保持当前值。[即时设置](../developer/settings.md#即时设置与界面偏好)

退出无需草稿确认，仍等待真实写入和 Host 签名许可；托盘退出等待期间保留窗口唤回与菜单操作。[桌面退出](../developer/desktop-authorization.md#退出与维护许可)

## 插件与界面

默认插件由 Setup 临时材料或 Portable 的一次性输入初始化，完成后清理；运行只加载 `runtime/extensions`。完整目录外部移除、部分损坏和父目录异常各按其证据处理，账号、配置与历史保留。[插件管理](../user/plugins.md) · [初始化与目录协调](../developer/extensions.md#首次初始化与目录变更)

运行中心保持卡片宽度并累计实际调用，可见日志合并刷新；队列连续编辑、账号摘要、插件搜索与排序沿当前身份和修订工作。MaaEnd/MaaS 继续作为纯数据专项调用已安装上游，MaaFramework 独立拥有框架执行能力。[前端](../developer/frontend.md) · [扩展](../developer/extensions.md)

正式发行资格、信任配置与渠道顺序由[发布流程](../developer/release.md)维护；本地验收报告记录实际源码、测量与未运行项。
