# 前端行为、公共组件与页面边界

`apps/web` 是浏览器与 Electron 共用的 Vue 应用。Host 提供 Web 资产，桌面通过受限原生桥加载同一界面；公共 Custom Elements、SDK 和 typed control client 共用现有契约。

## 页面与能力归属

| owner | 职责 |
|---|---|
| App shell | 实例、权限、连接、导航和界面会话 |
| Automation | 脚本、账号、绑定、队列的编辑状态及具名命令 |
| Records | 查询、分页、账号范围和稳定深链 |
| Logs / Media | 共享请求、有界缓冲、可见性和取消 |
| Extensions | 插件模块、挂载 scope 和生命周期通知 |
| Settings | 即时设置、确认值及原写入结果核对 |

页面取得所属任务需要的窄接口。公共组件只依赖公共行为，页面私有类型留在页面层；派生 lookup 随权威修订更新。已有 EventFeed、LiveLogs 和 MediaPool 继续管理共享资源。

## 表单与公共动作

插件中心和运行历史使用工作区剩余高度。标题和筛选保持可见，长列表与详情在各自卡片内滚动。窄屏切换卡片时沿用同一高度约束。

真实保存使用明确的提交路径，其他原生按钮显式设置 `type="button"`。选择、探测、查询和修复预览保留父表单。[脚本配置发现](../../apps/web/src/pages/ScriptSourceFields.vue)在根目录变更后运行；可编辑会话在主程序未填写时采用首个候选，发布前保留权限、取消与响应校验。

公共按钮、字段和动作集合统一 busy、disabled、键盘、焦点、校验与提交语义。Vue 封装适配模型与事件；弹窗页脚动作使用一致的最小 80px 宽度。开关行复用 `nexus-switch-list`，排序复用公共指针及键盘 owner。

计划与队列、脚本库、账号与配置以及通知的列表卡片使用可换行的静态标题。右侧动作使用带可访问名称的方形图标按钮，窄屏时仍与标题同行。

[FormDate](../../apps/web/src/components/FormDate.vue)的日期模式进入 [DateControl](../../apps/web/src/ui/date-control.ts)；时间模式与公共 `nexus-time-picker` 共用 [TimeControl](../../apps/web/src/ui/time-control.ts)。日期选中态由已提交值决定，键盘浏览与 Escape 保持提交边界。

通用脚本的四个根目录依赖字段由 [script-root](../../apps/web/src/pages/script-root.ts)管理：Host 确认目录实际存在后启用；核验中、失败、目录变化或会话变化立即锁定，取消与卸载丢弃晚到结果。核验只读，保存时仍执行正常路径和授权验证。

宿主与插件设置分类共用展开、置顶、排序、定位和可访问状态。选择分类后展开并定位，重复选择收起；直接操作卡片标题清除旧置顶。快速切换保留最后选择和阅读位置，插件通过公开挂载能力贡献内容。

## 编辑状态与设置

| 内容 | 生命周期事实源 |
|---|---|
| 新建、编辑、配置、通知与插件编辑草稿 | [Web 编辑会话](../reference/frontend-state.md#编辑草稿) |
| 概览预览、活动保存与宿主/壁纸即时设置 | [保存边界](../reference/settings.md#即时设置与界面偏好) |
| 插件草稿能力、父子结算与敏感输入 | [扩展前端](../reference/extension-frontend.md#编辑草稿能力) |
| 托盘、renderer 准备与签名退出许可 | [桌面授权](../reference/desktop-authorization.md#退出与维护许可) |

草稿存在、字段修改、展示恢复和请求在途分别管理。页面卸载释放读取及展示资源，已发送的写入继续由原操作 owner 结算。结果未知时保留原 operationId 并查询；修订冲突保留原编辑基线。

同一操作的反馈由原命令或表面呈现。请求在途时显示已有的忙碌状态，明确拒绝时提示失败，回执丢失时显示查询原操作的提示。预读失败由进入页面后的正式读取处理。Toast 栈负责定位和生命周期。

## 历史与登录的完整身份

账号历史链接由共用入口携带账号上下文，服务端详情、日志和图片沿冻结步骤过滤。整体运行入口使用运行身份；查询、稳定游标与容量边界见[启动与容量](startup.md)。

登录窗口先显示加载阶段，再访问已声明来源；候选凭据经过后端验证后返回编辑器。导航失败时原窗口提供刷新、完成并验证和取消。认证 iframe 的加载许可与凭据读取来源分别校验，秘密输入、披露授权和登录会话各自管理拥有期。

## 定向验证

真实父表单的非保存操作、账号历史深链、设置分类、草稿恢复与即时设置分别验证产品结果。保留焦点、最后数据可达、权限、取消和未知操作归属断言。

公共 ABI 改动扩到实际插件消费者；页面排版使用对应浏览器场景。命令见[验证规范](../development/validation.md)，公开元素见[前端 ABI](../reference/frontend-abi.md)，读取及资源细节见[Web 状态](../reference/frontend-state.md)。
