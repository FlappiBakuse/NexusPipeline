# NexusPipeline

Windows 11 x64 本地自动化管家，目标版本 0.18.0。

当前源码包含重构后的后端、九页共用 Web 前端及 Electron 桌面壳。
官方插件源码消费当前 SDK，包含五个浏览器模块及专项配置、执行与恢复流程。
按开发入口生成同源产物并分别完成合同、业务与产品验证；既有证据只适用于其明确绑定的源码和范围。
完整候选仍须通过成品验证和人工验收；受控集成不代表真实游戏、账号或设备已经验收。
